VoxPet Windows 테스트 패키지 (x64)

실행
1. ZIP을 새 폴더에 모두 풀고 START.cmd 또는 VoxPet.exe를 실행합니다.
2. 별도 .NET SDK/runtime 설치는 필요 없습니다. Assets/와 Licenses/도 함께 보관합니다.
3. Windows 11 x64를 우선 사용합니다. ARM64/32비트 Windows 검증용 패키지가 아닙니다.
4. 이 EXE는 unsigned입니다. 게시자 이름은 인증서로 검증되지 않았습니다.

통합 화면과 샘플
왼쪽 사이드바로 홈/캐릭터/의상/동작/방송·설정/편집기를 이동합니다.
설정도 같은 사이드바 안에서 열립니다. 별도 방송창은 출력 확인용입니다.
홈의 [의상 14종 · 동작 9종 샘플로 시작] → 의상 [착용] → 동작 [재생]을 누릅니다.
샘플은 모든 의상 분류와 손동작5종·권총/활/한손/양손 액션을 포함합니다.
같은 미리보기와 방송창에서 확인하고 [모두 해제]/[동작 중지]로 되돌립니다.
개인 캐릭터는 캐릭터 목록에서 다시 선택합니다. 샘플은 개인 파일을 바꾸지 않습니다.
Assets/Samples/studio-samples.voxpet와 LICENSE.txt도 함께 보관합니다.

마이크 없는 자동 검사
1. 다른 앱을 닫은 전용 Windows 테스트 환경 또는 가상머신에서 TEST-SMOKE.cmd를 실행합니다.
2. 약 1~3분 동안 합성 창이 열리고 키/마우스 입력을 시험합니다. 다른 작업은 잠시 멈춥니다.
   일부 검사는 실제 합성 키/좌클릭을 보내므로 작업 중인 일반 데스크톱에서는 수동 검사만 진행합니다.
3. PASS와 실패 0을 확인합니다. 실행한 컴퓨터에서 표시된 결과 폴더를 보관합니다.
4. 결과는 임시 폴더의 VoxPet-tests 아래 매번 새 폴더에 생성합니다.
5. 실제 마이크/개인 PNG/기존 사용자 설정을 사용하지 않습니다. 외부로 전송하지 않습니다.
6. SDK/Core 테스트·lint는 포함하지 않습니다. 해당 검사는 저장소의 qa.ps1을 사용합니다.
7. 자동 검사는 일반 앱과 달리 합성 입력을 보내며 PNG/JSON 증거를 로컬에 남깁니다.

수동 검사 (실제 마이크와 방송 환경)
[ ] 실행 직후 입력이 자동 시작되지 않고 이전 설정/캐릭터가 복원되는지 확인합니다.
[ ] 마이크 없이 데모 → 입/눈/몸 반응 → Stop → 음량 0을 확인합니다.
[ ] 마이크 선택 → Start → 말하기/침묵 → Stop을 10회 반복합니다.
[ ] Start 중 USB 마이크 제거 → 오류 안내 → Stop → 재연결/새로고침 → Start를 확인합니다.
[ ] Windows 마이크 접근 거부에서 오류 안내를 확인한 뒤 권한을 직접 허용하고 재시도합니다.
[ ] 방송창 크기·초록/투명·트레이 숨김/복원·앱 종료·재실행을 확인합니다.
[ ] OBS Window Capture의 Windows Graphics Capture로 초록+크로마 키/투명을 확인합니다.
[ ] .voxpet 등록·선택·표정·동작·부착물·편집·내보내기·재불러오기를 확인합니다.
[ ] 편집 중 미적용 값이 있을 때 삭제/앵커 드래그로 입력이 사라지지 않는지 확인합니다.
[ ] 동작/표정/부착물을 삭제한 뒤 미리보기와 슬라이더를 사용해 종료되지 않는지 확인합니다.
[ ] 잘못된 파일 적용은 기존 화면을 유지하는지 확인합니다.
[ ] 서로 다른 DPI의 모니터로 이동하고 다시 실행해 창과 미리보기를 확인합니다.
[ ] 60분 사용 후 반응·입력·메모리·핸들·정상 종료를 확인합니다.

결과 기록: Windows 버전/빌드, CPU, GPU/드라이버, DPI, 마이크 종류, OBS 버전/캡처 방식,
발생 순서, 기대/실제 동작과 통과/실패를 적습니다. 자동 합성 PASS가 위 실기를 대신하지 않습니다.
음성 녹음·장치 ID·개인 PNG·개인 경로를 공개 이슈나 공유 결과에 넣지 않습니다.
일반 앱의 마지막 최소 오류 기록: %LOCALAPPDATA%\VoxPet\last-error.json
추가 조작은 USER-GUIDE.txt를 확인하세요.
