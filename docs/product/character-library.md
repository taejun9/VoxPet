# 캐릭터 선택 — 늘보군과 펠리

캐릭터 탭 상단에서 **늘보군 / 펠리**를 선택한다. 미리보기와 방송창에 함께 반영하며 마이크를 중단하지 않는다. 마지막 선택은 자동 저장한다.

| 이름 | ID | 기존 개인 PNG | 새 파츠 세트 |
|---|---|---|---|
| 늘보군 | neulbo | Characters/늘보군.png · 입8단계/12표정 | CharacterId=neulbo |
| 펠리 | pelly | Characters/펠리.png · 입3단계/측면 | CharacterId=pelly |

새 [이미지 조합 세트](image-set-format.md)는 동일 Canvas의 파츠·눈/입·의상·무기·액션을 등록한다. 해당 캐릭터의 등록 세트가 있으면 개인 기본 시트 없이도 실행할 수 있다. 기존 PNG 시트/저장 슬롯/의상은 보존하며 **기존 PNG 사용**으로 돌아갈 때 선택 캐릭터의 파일을 불러온다.

이전 drawing-neulbo/neulbo-man/neulbo-girl 선택은 늘보군으로 복구한다. 오디오·표정·의상·손동작 설정과 개인 원본을 삭제하지 않는다. 파일이 없거나 손상되면 현재 그림을 유지하고 안내한다. 재시작 중 복원할 이미지가 모두 없으면 내장 고양이를 기술적 대체 이미지로 사용한다. 공개 패키지에는 개인 그림을 넣지 않는다.

## 이전 다섯 종 제작 기록

plan021에서는 늘보군 / 그림 늘보군 / 늘보맨 / 늘보걸 / 펠리 다섯 종을 제작·검증했다. 아래 내용은 과거 자산 제작 기록이며 현재 선택 목록과 구분한다.

## 자산 제작과 원본 보존

사용자가 제공한 네 이미지를 참고해 내장 image_gen 도구로 투명 RGBA 1536×1024(512px 셀3열×2행) 시트를 제작했다. 위 행은 눈 뜸, 아래 행은 눈 감음이고, 왼쪽부터 입 닫힘/조금 열림/크게 열림이다. 펠리는 한쪽 눈이 보이는 측면으로 재생성했다. 생성 그림은 참고 이미지에서 파생한 그림이며 픽셀 단위 원본 추출은 아니다.

Downloads 원본과 기존 늘보군12PNG는 변경하지 않는다. 최종 신규 시트는 ignored `artifacts/characters/plan021/Characters/`에, 생성 프롬프트와 파일 SHA256/알파·셀 확인 결과는 같은 폴더의 상위 기록에 보관한다. 기본 도구를 사용했으며 CLI/API fallback은 사용하지 않았다. 개인 캐릭터 PNG와 참고 이미지는 Git/공개 CI로 전송하지 않는다.

## 검증 경계

Core는 목록/설정 호환·복구를 검사하고 CharacterSelectionQa는 임시 합성 PNG로 다섯 항목의 실제 WPF 선택·입/눈·창 공유·연속 선택·표정 테스트 취소·누락/손상·종료를 검사한다. 일반 EXE 시작 fixture는 펠리 선택 복원/저장 및 누락·손상 시 늘보군 복구를 확인한다. 개인 그림의 실제 픽셀은 로컬 시각/PNG 검사로 구분한다.

실기 상태는 [Windows 체크리스트](../quality/windows-checklist.md), 명령은 [개발 환경](../quality/development.md)을 따른다.

## plan025 변경

현재 선택 목록은 **늘보군 / 펠리** 두 종이다. 위 다섯 종 제작·검증 기록은 과거 기록이며 현재 선택 UI와 구분한다. 이전 drawing-neulbo/neulbo-man/neulbo-girl 선택은 늘보군으로 복구하되 오디오·표정·의상 설정과 개인 원본을 보존한다. 이전 캐릭터의 손동작 연결 설정도 파일에서 삭제하지 않는다. 새 [이미지 조합 세트 규격](image-set-format.md)을 지원하며 기존3·8열 PNG 시트도 계속 사용할 수 있다.
