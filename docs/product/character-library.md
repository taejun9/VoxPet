# 다섯 캐릭터 선택

캐릭터 탭 상단에서 **늘보군 / 그림 늘보군 / 늘보맨 / 늘보걸 / 펠리**를 선택한다. 미리보기와 기존 방송창에 함께 반영하며 마이크 입력을 중단하지 않는다. 정상 종료하면 선택한 ID를 로컬 설정에 저장한다.

| 이름 | ID | 개인 패키지의 파일 | 입 단계 |
|---|---|---|---|
| 늘보군 | neulbo | Characters/늘보군.png | 기존8단계·12표정 보존 |
| 그림 늘보군 | drawing-neulbo | Characters/그림 늘보군.png | 3단계 |
| 늘보맨 | neulbo-man | Characters/늘보맨.png | 3단계 |
| 늘보걸 | neulbo-girl | Characters/늘보걸.png | 3단계 |
| 펠리 | pelly | Characters/펠리.png | 3단계·왼쪽 측면 |

모든 캐릭터는 눈 깜박임을 지원한다. 신규 네 캐릭터는 평상 시트만 제공한다. 표정의 눈물/모션 설정은 적용하지만, 별도 얼굴 그림이 없는 종류는 선택한 캐릭터의 평상 얼굴을 유지한다. 캐릭터 선택은 저장된 사용자 PNG 슬롯과 의상 배치를 수정하지 않는다. 저장된 PNG 슬롯을 누르면 그 슬롯의 캐릭터가 우선 표시되며 **선택 캐릭터로 복원**으로 선택한 캐릭터의 평상 모습으로 돌아온다. 시작할 때는 기존처럼 F1 저장 슬롯을 적용한다.

이미지가 누락되거나 손상된 선택은 현재 캐릭터를 유지하고 안내한다. 재실행 중 저장한 캐릭터 파일이 없으면 늘보군으로 복구하며, 늘보군도 없으면 내장 Violet Cat을 사용한다. 캐릭터 ID 오류가 오디오/방송창 설정까지 초기화하지 않도록 별도 복구한다. 공개 패키지에는 개인 PNG를 넣지 않으므로 다섯 선택에는 개인 패키지의 Characters 폴더가 필요하다.

## 자산 제작과 원본 보존

사용자가 제공한 네 이미지를 참고해 내장 image_gen 도구로 투명 RGBA 1536×1024(512px 셀3열×2행) 시트를 제작했다. 위 행은 눈 뜸, 아래 행은 눈 감음이고, 왼쪽부터 입 닫힘/조금 열림/크게 열림이다. 펠리는 한쪽 눈이 보이는 측면으로 재생성했다. 생성 그림은 참고 이미지에서 파생한 그림이며 픽셀 단위 원본 추출은 아니다.

Downloads 원본과 기존 늘보군12PNG는 변경하지 않는다. 최종 신규 시트는 ignored `artifacts/characters/plan021/Characters/`에, 생성 프롬프트와 파일 SHA256/알파·셀 확인 결과는 같은 폴더의 상위 기록에 보관한다. 기본 도구를 사용했으며 CLI/API fallback은 사용하지 않았다. 개인 캐릭터 PNG와 참고 이미지는 Git/공개 CI로 전송하지 않는다.

## 검증 경계

Core는 목록/설정 호환·복구를 검사하고 CharacterSelectionQa는 임시 합성 PNG로 다섯 항목의 실제 WPF 선택·입/눈·창 공유·연속 선택·표정 테스트 취소·누락/손상·종료를 검사한다. 일반 EXE 시작 fixture는 펠리 선택 복원/저장 및 누락·손상 시 늘보군 복구를 확인한다. 개인 그림의 실제 픽셀은 로컬 시각/PNG 검사로 구분한다.

실기 상태는 [Windows 체크리스트](../quality/windows-checklist.md), 명령은 [개발 환경](../quality/development.md)을 따른다.
