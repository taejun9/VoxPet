# VoxPet 사용 설명서

기본 화면은 VoxPet 2.0 대시보드입니다. 홈의 **시작 / 중지**는 아래 Start/Stop과 같은 기능입니다. **방송 / 설정**을 누르면 기존 입력·반응·PNG 시트·표정·의상·액션 설정 화면을 열며, 그 화면의 **홈** 버튼으로 돌아옵니다. 기존 설정 화면의 입력 버튼은 **입력 시작 / 입력 중지**입니다.

VoxPet은 마이크 음량에 맞춰 PNG 캐릭터의 입과 몸을 움직이는 Windows 앱이다.
음성은 로컬 메모리에서만 분석하며 저장하거나 전송하지 않는다. 데모는 마이크를 사용하지 않는다.

처음 사용하는 분을 위한 별도 문서는 **[설치 방법](guides/installation.md) → [사용 방법](guides/usage.md) → [설정 방법](guides/settings.md)** 순서로 읽는다. 다운로드부터 마우스로 따라 하는 순서를 설명하며 프로그래밍 지식은 필요 없다. 아래 본문은 전체 기능과 수치의 상세 안내다.

## 처음 사용하는 경우

1. Windows x64 배포 ZIP을 폴더에 모두 풀고 `VoxPet.exe`를 실행한다.
2. **마이크 없이 데모**를 누른다. 캐릭터의 입과 몸이 움직이고 눈이 깜빡이는지 확인한다. **Stop**으로 데모를 끝낸다.
3. 마이크 목록에서 입력 장치를 선택한다. 목록이 비어 있으면 연결과 권한을 확인한 뒤 **↻**를 누른다.
4. **Start**를 누르고 평소 목소리로 말한다. 하단의 **분석 중** 상태, 입력 수치와 캐릭터 반응을 확인한다.
5. **일반 대화**를 기준으로 조정한다. 작은 목소리는 **조용한 목소리**, 빠른 입 움직임은 **빠른 반응**을 시도한다.
6. 마이크를 해제할 때는 **Stop**을 누른다. 메인 설정창을 닫으면 마이크 종료 후 방송창도 닫힌다.

방송창이나 캐릭터 음소거만으로 마이크가 해제되지 않는다. 앱이 시작될 때 자동으로 마이크 분석을 시작하지 않는다.

## 화면에서 확인할 항목

| 영역 | 표시와 조작 |
|---|---|
| 미리보기 | 현재 캐릭터, 입·눈·몸 움직임, 방송창 열기 |
| VOICE LEVEL | Gate·감도·시간 평활화를 적용한 0~100% 입 반응 |
| RAW | dBFS를 입력 범위로 정규화한 0~100%; Gate·감도·평활화 적용 전 값 |
| RMS / Peak / dBFS | 평균 에너지의 크기, 최대 샘플 크기, full scale 기준 상대 입력 레벨 |
| 마이크 | 장치 선택, ↻ 새로고침, Start, Stop, 마이크 없는 데모, Windows 마이크 권한 설정 열기 |
| 반응 조정 | 프리셋, 기본값, Gate·감도·Attack·Release, 3초 주변 소음 측정·추천 적용·취소 |
| 작은 목소리: 입력 반응 범위 | 낮은 입력·높은 입력의 정규화 구간 |
| 방송·캐릭터 옵션 | 항상 위·초록 배경·PNG 시트 불러오기·기본 캐릭터 |
| 안내 | 하단 마이크 상태와 별도의 PNG 불러오기 결과 |

RAW가 올라가도 Gate가 닫혀 있거나 캐릭터 음소거가 켜져 있으면 입이 열리지 않을 수 있다. Stop 후에는 레벨과 측정 표시가 초기화되지만 눈 깜빡임과 대기 움직임은 계속된다.

## 실행

Windows x64에서 배포 폴더의 `VoxPet.exe`를 실행한다. 자체 포함 배포본은 .NET 설치가 필요 없다.
폴더의 Licenses와 자산 manifest는 실행 파일과 함께 보관한다.
현재 권장 검증 대상은 Windows 11 x64의 지원 중인 버전이다. Windows 10 전체 버전의 호환성을 보장하지 않는다.
빌드와 UI smoke 통과 여부는 [검증 기록](quality/windows-checklist.md)에서 확인한다.
개발 실행/배포 명령은 [개발 환경](quality/development.md)에 있다.

설정창은 기본 크기를 주 화면의 작업 영역에 맞춰 연다. 좁거나 낮은 창에서는 공통 미리보기를 숨기고 설정 탭을 넓힌다. 캐릭터 탭에서는 미리보기를 계속 볼 수 있다.
상단 탭으로 조정값과 미리보기를 선택한다. 작은 창은 내용 크기를 줄여 스크롤 없이 표시한다. 최소 크기는 480×320 논리 단위이며, 실제 모니터 DPI 변경은 [검증 기록](quality/windows-checklist.md)에서 별도로 확인한다.

1. 마이크를 선택한다. 연결 후 목록에 없으면 ↻로 새로고침한다.
2. Start를 누르고 말한다. 분석 중 상태와 선택 장치가 하단에 표시된다.
3. 캐릭터가 너무 자주 반응하면 Noise Gate를 높인다. 말할 때 반응이 약하면 Sensitivity를 올린다. 아주 작은 입력은 고급 입력 반응 범위에서 낮은 입력과 Gate를 함께 낮춘다.
4. Attack은 입이 열리는 속도, Release는 닫히는 속도다. 값이 클수록 천천히 반응한다.
5. Stop은 캡처를 해제하고 레벨을 0으로 초기화한다. 장치 교체는 Stop 이후 선택한다.
6. 마이크 없이 데모 버튼으로 캐릭터·방송창 동작을 확인한다. Stop으로 종료한다.

RMS/Peak는 full scale 기준이고 dBFS는 상대 레벨이다. 실제 음압 dB SPL이나 발화 여부를 판정하지 않는다.
Peak가 1 이상이면 CLIP이 표시된다. Windows 입력 볼륨을 낮춰 확인한다.
Gate는 음성과 키보드 같은 소음을 의미적으로 구별하지 못한다.
무입력이 250ms 넘게 지속되면 레벨을 무음으로 취급하고 Release를 적용한다.

## 반응 조정 방법

먼저 평소 목소리로 말하고 잠시 침묵하면서 dBFS와 입 움직임을 비교한다. 한 번에 하나의 값을 바꾸면 조정 결과를 이해하기 쉽다.

| 조정값 | 기본값 / UI 범위 | 사용 방법 |
|---|---|---|
| Noise Gate | -50 dBFS / -90~-10 | 측정값이 Gate 미만이면 입을 닫는 방향으로 움직인다. -50에서 -40으로 높이면 작은 입력을 더 많이 막는다. |
| Sensitivity | 1.0× / 0~4 | Gate를 통과한 정규화 레벨에 곱한다. 올리면 같은 입력에 더 크게 반응한다. 0이면 음량에 따른 입 반응이 사라진다. |
| Attack | 40ms / 0~300 | 입이 열리는 시간 상수. 줄이면 빠르게, 늘리면 부드럽게 열린다. |
| Release | 140ms / 0~1000 | 입이 닫히는 시간 상수. 줄이면 빠르게, 늘리면 천천히 닫힌다. |
| 낮은 입력 | -50 dBFS / -120~-1 | RAW가 0이 되는 기준. 작은 목소리가 여기에 못 미치면 이 값과 Gate를 낮춘다. |
| 높은 입력 | -10 dBFS / -119~0 | RAW가 100%가 되는 기준. 낮추면 더 작은 입력에서도 최대 반응에 도달한다. |

낮은 입력은 높은 입력보다 작아야 한다. 슬라이더를 교차시키면 앱이 상대 경계를 함께 조정한다. Attack/Release의 ms는 반응이 완전히 끝나는 시간이 아니라 평활화의 시간 상수다. 0ms는 다음 시간 갱신에서 즉시 목표 레벨을 따른다.

- 침묵 중에도 입이 자주 열리면 Gate를 올리고 배경 소음을 확인한다.
- 작은 목소리에 반응하지 않으면 조용한 목소리 프리셋을 먼저 적용한다. 필요하면 Gate와 낮은 입력을 낮춘 뒤 감도를 조정한다. 감도만 올려도 Gate를 통과하지 못한 입력은 반응하지 않는다.
- 입이 너무 쉽게 완전히 열리면 감도를 낮추거나 높은 입력을 올린다.
- 짧은 음절이 뭉개지면 Attack을 줄인다. 말이 끝난 뒤 입이 너무 오래 열려 있으면 Release를 줄인다.
- CLIP이 자주 보이면 Windows 입력 볼륨을 낮춘다. 앱 감도는 캐릭터 반응을 조정하므로 입력 자체의 clipping을 해결하지 않는다.

입 모양은 Voice Level 20% 미만이면 닫힘, 20% 이상~60% 미만이면 중간, 60% 이상이면 열림이다.

## 반응 프리셋과 캐릭터 음소거

반응 조정의 **일반 대화**, **조용한 목소리**, **빠른 반응**을 누르면 Gate·입력 범위·감도·Attack·Release를 함께 바꾼다.
조용한 목소리는 낮은 입력에 반응하고, 빠른 반응은 입이 더 빨리 열리고 닫힌다. 적용 후 슬라이더로 미세 조정할 수 있다.
기본값은 일반 대화 설정을 복원한다. 프리셋은 발화/소음을 의미적으로 분류하지 않는다.

| 프리셋 | Gate | 낮은 / 높은 입력 | 감도 | Attack / Release |
|---|---|---|---|---|
| 일반 대화 / 기본값 | -50 dBFS | -50 / -10 dBFS | 1.0× | 40 / 140ms |
| 조용한 목소리 | -65 dBFS | -65 / -20 dBFS | 1.2× | 50 / 180ms |
| 빠른 반응 | -45 dBFS | -45 / -10 dBFS | 1.0× | 15 / 80ms |

**캐릭터 음소거**를 켜면 입 반응과 VOICE LEVEL이 즉시 0으로 바뀐다. 눈깜빡임과 대기 움직임, RAW/RMS/Peak 표시는 계속된다.
마이크 캡처도 계속되므로 마이크를 해제하려면 **Stop**을 누른다. 음소거를 끄면 현재 입력에 다시 반응한다.
음소거는 다음 실행에 유지되지 않는다.

## 내 PNG 캐릭터 불러오기

**PNG 시트 불러오기**에서 로컬 파일을 선택하면 미리보기와 열린 방송창에 함께 적용한다. 마이크 없이 데모로 시험할 수 있다.
시트는 8비트 RGBA 투명 PNG 하나이며 16MB 이하, 정사각형 셀 3열×2행(셀 128~1024px, 예: 전체 1536×1024px)이다.
각 셀에 투명 여백과 완전한 캐릭터를 넣고, 모든 상태의 몸 크기를 같게 만든다. 셀별 중앙과 바닥 위치는 자동 정렬한다.

| 행 / 열 | 첫째 열 | 둘째 열 | 셋째 열 |
|---|---|---|---|
| 첫째 행 (눈 뜸) | 입 닫힘 | 입 중간 | 입 열림 |
| 둘째 행 (눈 감음) | 입 닫힘 | 입 중간 | 입 열림 |

취소하거나 잘못된 파일을 선택하면 기존 캐릭터를 유지한다. **기본 캐릭터**로 패키지의 기본 캐릭터를 복원한다(개인 패키지는 늘보군).
파일을 적용한 뒤 원본 파일은 앱이 점유하지 않는다. 일반 불러오기의 개인 캐릭터/파일 경로는 설정에 저장하지 않으므로 다음 실행에 다시 불러온다. 표정 슬롯에 저장하면 관리 복사본은 재실행에도 유지된다.
이용 권리가 있는 파일을 사용한다. 첨부 늘보군은 개인 시험 시트이며 기본 공개 배포에 포함하지 않는다.

준비한 파일은 다음 순서로 적용한다.

1. 이미지 편집기에서 각 상태의 완전한 캐릭터를 같은 크기 셀에 넣는다. 예를 들어 512×512px 셀 6개를 배치하면 전체 크기는 1536×1024px이다.
2. 모든 셀에 실제 투명 픽셀과 캐릭터가 있는지 확인하고 8비트 RGBA PNG로 내보낸다. 흰 배경을 투명 배경처럼 취급하지 않는다. 완전히 빈 셀과 투명 여백 없는 셀은 거부된다.
3. **PNG 시트 불러오기**로 선택하고 캐릭터 안내의 적용 완료를 확인한다.
4. 데모에서 입 세 단계와 눈 감음을 확인한다. 방송창이 열려 있으면 같은 캐릭터가 즉시 반영된다.

자동 정렬은 셀 안의 캐릭터를 이동하는 기능이며 몸 크기를 통일하는 기능은 아니다. 상태마다 크기가 다르면 입을 바꿀 때 몸이 커지거나 작아질 수 있으므로 원본에서 맞춘다.

## OBS 방송창

캐릭터 방송창 열기를 누르면 설정 화면과 별개의 `VoxPet Character` 창이 열린다.
두 창은 하나의 마이크 세션과 캐릭터 상태를 공유한다. 방송창만 닫아도 분석은 계속된다. 설정창을 최소화해도 방송창은 계속 표시된다.
방송창을 드래그해 이동하고 우측 하단에서 크기를 조절한다. Esc 또는 우클릭 메뉴로 닫는다.

OBS에 Window Capture 소스를 추가해 `VoxPet Character`를 선택한다.

처음 연결할 때의 권장 순서는 다음과 같다.

1. VoxPet에서 **초록 배경 (OBS)**을 켜고 방송창을 연다.
2. OBS의 사용할 장면에서 **소스 추가 → 윈도우 캡처(Window Capture)**를 선택한다.
3. 대상 창을 **VoxPet Character**로 지정하고 Windows Graphics Capture 방식을 선택한다.
4. 해당 소스의 **필터 → 크로마 키(Chroma Key)**를 추가하고 키 색상을 Green으로 지정한다.
5. OBS 미리보기에서 배경 제거와 입·눈·몸 반응을 확인한 뒤 크기와 위치를 맞춘다. 초록색이 포함된 개인 캐릭터는 크로마 키로 그 부분도 제거될 수 있으므로 결과를 확인한다.

방송창은 캐릭터 화면을 제공한다. 방송에 목소리를 넣으려면 OBS에서 마이크 오디오 소스도 따로 설정한다. **방송창 항상 위**는 다른 창 위에 표시하는 옵션이며 캡처 성공을 보장하는 옵션은 아니다.
캡처 방식은 Windows Graphics Capture(OBS에서 Windows 10 이상 방식)를 먼저 시도한다. OBS 32.2.2/Windows Server 2025의 합성 데모 검증에서 이 방식은 통과했고 BitBlt는 유효한 프레임을 얻지 못했다. 사용자 GPU/Windows 조합은 별도 확인한다.
초록 배경을 켜고 OBS의 Chroma Key 필터에서 Green을 선택하면 배경을 제거할 수 있다.
초록 배경을 끄면 WPF 창이 투명해지지만, OBS 캡처에서 alpha가 보존되는지는 버전/방식에 따라 실기 검증이 필요하다.
위 OBS 32.2.2/WGC 합성 시험에서는 native alpha도 보존됐다. 사용자 환경에서 검은 배경이나 캡처 실패가 보이면 초록 배경과 Chroma Key를 사용한다.
최소화/가림/스케일/장시간 캡처는 [체크리스트](quality/windows-checklist.md)로 확인한다.

## 오류 해결과 저장 설정

- 마이크 없음: USB/오디오 연결과 Windows 소리 설정의 입력 장치를 확인한 뒤 새로고침한다.
- 접근 거부: Windows 설정의 개인정보 및 보안 → 마이크 → 데스크톱 앱의 마이크 접근 허용을 확인한다.
- 연결 제거/캡처 중단: 자동으로 무음과 오류 안내로 전환한다. 다시 연결하고 새로고침 → Start로 재시작한다.
- 종료 지연: 5초를 넘으면 오류를 표시하며 사용 중인 캡처를 강제로 해제하지 않는다. 잠시 후 Stop/앱 종료를 다시 시도한다.
- 설정은 앱 종료 때 `%LOCALAPPDATA%\VoxPet\settings.json`에 저장한다. 조정값과 방송창 배경/항상 위 옵션만 포함한다.
- 설정 파일이 손상되면 기본값으로 시작한다. 기본값 버튼은 오디오 슬라이더를 초기화한다.
- 기본 캐릭터는 독자 제작한 CC0 PNG 36장(표정6종×입3×눈2)이며 [manifest](../src/VoxPet.App/Assets/Characters/manifest.json)에 크기/anchor/출처를 기록했다.

마이크 캡처·Windows/OBS 실기·DPI/장시간 검증이 끝나기 전에는 정식 실사용 검증 완료 버전으로 취급하지 않는다.

### 증상별 확인 순서

| 증상 | 확인과 조치 |
|---|---|
| Start를 누를 수 없음 | 데모를 Stop으로 끝내고 마이크를 선택한다. 장치 목록이 비었으면 연결·권한 확인 후 ↻를 누른다. 시작/종료 처리 중이면 완료를 기다린다. |
| 입력 수치가 계속 0 | Start 후 분석 중 상태인지 확인하고 Windows 소리 설정의 입력 장치·볼륨을 확인한다. 다른 장치는 Stop → 선택 → Start 순서로 바꾼다. |
| 수치는 변하지만 입이 안 움직임 | 캐릭터 음소거를 끄고 감도가 0인지 확인한다. Gate와 낮은 입력을 확인하거나 일반 대화/조용한 목소리를 적용한다. |
| PNG를 불러오지 못함 | 16MB 이하, 8비트 RGBA, 3열×2행 정사각형 셀, 셀 크기 128~1024px, 각 셀의 캐릭터·투명 픽셀을 확인한다. 팔레트/RGB PNG는 RGBA로 다시 내보낸다. |
| OBS에서 검은 배경·빈 화면 | 대상 창과 WGC 방식을 확인한다. 초록 배경과 Green 크로마 키를 적용하고 데모로 캡처 여부를 확인한다. |
| 다음 실행에서 개인 캐릭터가 사라짐 | 일반 불러오기는 저장하지 않는다. 슬롯 PNG 선택 → 슬롯 저장으로 재실행에도 유지한다. |
| 설정이 유지되지 않음 | 앱을 정상 종료했는지와 설정 경로의 쓰기 권한을 확인한다. 손상된 설정은 기본값으로 시작한다. |

### 저장되는 값과 초기화 범위

| 항목 | 재실행 시 유지 |
|---|---|
| Gate·입력 범위·감도·Attack·Release | 정상 종료 시 저장 |
| 방송창 항상 위·초록 배경 | 정상 종료 시 저장 |
| 선택 마이크·개인 PNG 원본 경로·일반 불러오기 캐릭터 | 저장하지 않음 |
| 표정 슬롯 설정·슬롯 PNG 관리 복사본 | 슬롯 저장 버튼으로 즉시 저장 |
| 캐릭터 음소거·데모·실행 중 음량 | 저장하지 않음 |

**기본값**은 오디오 조정값을 일반 대화로 돌리고, **기본 캐릭터**는 내장 이미지를 복원한다. 두 버튼 모두 방송창 옵션을 초기화하지 않는다. 오디오·방송창 저장 설정을 초기화하려면 앱을 종료한 뒤 `%LOCALAPPDATA%\VoxPet\settings.json`을 다른 이름으로 옮겨 보관하고 다시 실행한다.

## 표정 슬롯과 단축키

1. **표정 · 단축키 슬롯**에서 편집할 F1~F12 슬롯을 선택합니다.
2. 이름과 기본 표정(평상부터 장난까지12종)을 선택합니다. F3은 처음에 눈물을 흘리는 슬픈 표정입니다.
3. **눈물** 탭에서 **눈 깜빡임**, **눈물 모션**을 선택하고 눈물의 왼쪽·오른쪽·높이를 조정합니다. **표정 미리보기**로 확인합니다.
4. **슬롯 저장**을 누릅니다. 저장은 즉시 로컬에 반영되며 다음 실행에서도 유지됩니다. 시작할 때 F1 슬롯을 표시합니다.
5. Ctrl+Shift+F1~F11 또는 슬롯 버튼으로 마지막 저장한 표정으로 전환합니다. 약 240ms 동안 부드럽게 전환하고 연속 입력에서는 최신 요청을 표시합니다.

Ctrl+Shift+F1~F11은 설정창을 최소화하거나 다른 앱을 사용해도 동작합니다. 다른 앱이 같은 키를 점유하면 등록 실패한 키를 표시합니다. 해당 키는 VoxPet 창 안에서 사용하거나 슬롯 버튼을 누르세요. 다른 앱을 종료한 뒤 VoxPet을 재시작하면 다시 등록합니다.
Windows가 F12를 디버거 키로 예약하므로 **Ctrl+Shift+F12는 설정창 또는 방송창에 포커스가 있을 때만** 동작합니다. 슬롯 버튼은 항상 사용할 수 있습니다.

**슬롯 PNG 선택**은 해당 표정의3열 또는8열×2행 RGBA 시트를 선택합니다. 규격은 기존 개인 캐릭터 시트와 같습니다. 각 시트에 눈 뜸/감음과 입 3단계를 직접 그려 넣어야 합니다. 사용자 시트에 내장 얼굴 모양을 덧그리지 않습니다. **내장 표정 사용**을 누르면 해당 슬롯의 시트를 해제하고 선택한 기본 표정으로 돌아갑니다. 변경 후 미리보기·저장을 누르세요.

일반 **PNG 시트 불러오기**는 현재 실행에만 적용됩니다. **슬롯 PNG 선택 → 슬롯 저장**은 검증한 시트를 앱의 관리 폴더에 복사하므로 원본을 옮기거나 삭제해도 사용할 수 있습니다. 원본 경로는 저장하지 않습니다. 이용 권리가 있는 이미지만 선택하세요.

슬롯별 JSON과 PNG 복사본 위치: `%LOCALAPPDATA%\VoxPet\Expressions`. 슬롯 JSON이 손상되면 해당 슬롯만 기본값으로 돌아갑니다. 저장된 PNG가 손상되면 현재 표시를 유지하고 복구 안내를 표시합니다. 해당 슬롯에 정상 PNG를 다시 저장하거나 내장 표정을 저장하세요. 초기화하려면 앱을 종료하고 Expressions 폴더를 다른 이름으로 옮겨 보관합니다. settings.json을 초기화해도 표정 슬롯은 유지됩니다.

눈 깜빡임·대기 움직임·눈물은 마이크와 독립적으로 움직이므로 Stop/무음/캐릭터 음소거 중에도 계속됩니다. 눈물 좌표는 캐릭터의 512 단위 화면에 맞춰 확대·축소되어 미리보기와 방송창에서 동일하게 표시됩니다.

## 주변 소음 추천과 방송 중 입 음소거

Start 후 **주변 소음 측정 (3초)**를 누르고 말하지 않고 기다린다. 추천값이 표시되어도 기존 값은 유지되며 **추천값 적용**을 눌러 Gate만 변경한다. 적용 후 작은 목소리로 말해 확인한다. 무신호·큰 소음은 추천하지 않는다. 측정 취소/Stop/프리셋/종료는 진행 중 측정과 대기 추천을 폐기한다. [단계별 설정 안내](guides/settings.md#주변-소음으로-noise-gate-추천받기)를 따른다.

**Ctrl+Shift+M**은 전역 캐릭터 입 음소거다. 키 충돌 안내가 나오면 VoxPet 창 안에서 같은 키 또는 체크박스를 사용한다. 마이크 캡처/RAW/blink는 계속되며 OBS/Windows 음소거와 자동 동기화하지 않는다. 마이크 해제는 Stop을 누른다. **Windows 마이크 권한 설정 열기**는 사용자 클릭으로 OS 설정 페이지를 열며 자동 권한 변경이나 자동 Start를 하지 않는다.

## 상단 설정 탭과 개인 기본 캐릭터

마이크·반응·캐릭터·표정·눈물·의상 탭을 눌러 각 설정을 스크롤 없이 표시합니다. 작은 창에서는 내용 크기를 줄이며 캐릭터 탭에서도 미리보기를 볼 수 있습니다. 캐릭터 탭의 너비·높이 슬라이더 또는 방송창 우클릭 메뉴로 크기를 조절하고, 우하단 모서리 드래그도 사용할 수 있습니다. 크기는 200~1200 DIP, 이번 실행 동안 유지합니다.

개인 늘보군 패키지는 실행 파일 옆 `Characters/늘보군.png`를 기본 시작/복원/내장 표정의 캐릭터로 사용합니다. 파일이 없거나 잘못되면 내장 고양이로 시작합니다. 저장된 사용자 PNG 슬롯은 그대로 보존하고 시작 F1 슬롯을 우선 적용합니다. 기본 시트가 하나뿐이면 그 입·눈 상태를 공유하며, 표정별 PNG가 있으면 각각의 얼굴을 사용합니다. 개인 PNG는 공개 저장소/기본 공용 배포에 포함하지 않습니다.

세부 탭 안내: 마이크 → 입력 / 음소거·권한, 반응 → 음량 / 소음 측정 / 속도 / 입력 범위, 캐릭터 → 미리보기 / 방송창 / PNG, 표정 → 전환 / 편집 / PNG / 테스트. 눈물 탭은 깜빡임·눈물 위치와 미리보기·저장을 표시합니다.


## 늘보군 표정과 상세 입 반응

개인 plan016 패키지는 평상·기쁨·슬픔·화남·놀람·졸림·부끄러움·뿌듯함·갸우뚱·신남·애정·장난의 서로 다른 늘보군 얼굴12종을 포함합니다. **표정 → 테스트**에서12개 버튼으로 개별 얼굴을 확인하거나 **12종 전체 테스트**로 순회합니다. 입력이 중지되어 있으면 마이크 없이 숫자 데모로 입 움직임도 표시하고, 완료/중지하면 원래 표정과 입력 상태로 돌아옵니다. 이미 실행 중인 마이크나 데모는 유지합니다. 개별 표정 또는 슬롯 전환은 전체 테스트를 끝내고 새 표정을 표시합니다. 테스트는 저장한 슬롯/PNG를 바꾸지 않습니다. 이전 저장값이 있으면 새 얼굴을 기본 슬롯에 자동 덮어쓰지 않으므로 테스트 탭에서 모두 확인하세요. 해당 슬롯을 새 늘보군 얼굴로 바꾸려면 표정→편집에서 종류를 선택하고 표정→PNG의 내장 표정 사용 후 슬롯 저장을 누릅니다.

입은 닫힘부터 최대 열림까지8단계로 반응합니다. RAW dBFS가 Gate·입력 범위·감도·Attack/Release를 거친0~1 반응값에 따라 바뀌므로 고정된 절대 데시벨 표가 아닙니다. 실제 목소리를 듣거나 감정을 판별하지 않습니다. 조용한 목소리가 잘리지 않게 Gate/입력 범위를 맞추고 감도를 조절하세요. 무음·Stop·입 음소거는 입을 닫으며 깜빡임과 눈물은 독립적으로 동작합니다.

기존3열×2행 PNG/저장 슬롯은 계속 지원합니다. 상세 PNG는 정사각형 셀8열×2행이며 위쪽은 눈 뜸, 아래쪽은 눈 감음, 왼쪽부터 입이 점차 커집니다. 상세 셀은128~512px, 기존3열은128~1024px, 파일은16MB 이하8비트 RGBA입니다. 기본 파일은 Characters/늘보군.png, 표정별 파일은 Characters/늘보군-표정/happy.png, sad.png, angry.png, surprised.png, sleepy.png, shy.png, smug.png, confused.png, excited.png, love.png, playful.png입니다. 표정 파일이 잘못되거나 없으면 평상 시트를 사용하며 기존 설정을 삭제하지 않습니다. 개인 자산은 공개 Git/CI에 포함하지 않습니다.


## 표정 순서 변경

**표정 → 편집**에서 슬롯을 고른 뒤 **↑ 위로 / ↓ 아래로**를 누릅니다. 순서는 즉시 저장되며 다음 실행에도 유지됩니다. 표시된 F1~F12 버튼과 단축키, 테스트 버튼은 새 순서를 따릅니다. 표정 이름·눈물·PNG와 저장하지 않은 편집 초안은 함께 유지됩니다. 처음/마지막 항목은 해당 방향 이동 버튼이 꺼집니다. 저장 실패 시 기존 순서를 유지합니다.

순서는 `%LOCALAPPDATA%\VoxPet\Expressions\order.json`에 별도로 저장합니다. 파일이 없거나 손상되면 원래 슬롯 순서를 사용하며 슬롯 JSON/PNG는 보존합니다. 기본 순서로 돌아가려면 앱을 종료하고 order.json만 다른 이름으로 옮겨 보관합니다. 방송창 우클릭 메뉴는 흰 배경과 검정 글씨로 표시합니다.


## 트레이·OBS 호환 방송창·시작 오류

**트레이로 이동**은 설정창만 숨기고 방송창과 입력/데모를 유지합니다. 트레이 두 번 클릭/우클릭→설정창 열기로 복원하며 우클릭→종료로 전체 앱을 끝냅니다. X는 기존처럼 종료입니다. [트레이 단계별 안내](guides/usage.md#트레이로-이동하기)를 따릅니다.

OBS에서 보이지 않으면 **캐릭터 → 방송창 → OBS 호환 방송창 열기**로 초록 배경을 켜고 OBS 창 캡처 대상 **VoxPet Character**, 방식 **Windows 10(1903 이상)**을 지정합니다. plan019부터 투명/초록 전환은 같은 방송창과 크기·위치를 유지합니다. OBS 방식은 Windows 10(1903 이상)/WGC를 사용하세요. [OBS 복구 단계](guides/settings.md#obs3222에서-캐릭터가-보이지-않을-때)를 따릅니다.

plan016의 시작 오류는 WPF 초기 선택 해제 중 이동 명령이 null을 참조한 회귀였습니다. plan018에서 마지막 유효 선택을 유지하도록 수정하고 일반 인수 없는 EXE/저장 상태/12PNG 가족을 별도 프로세스로 검사합니다. 오류가 계속되면 [오류 기록 안내](guides/settings.md#실행-직후-종료-문제와-오류-기록)를 확인하세요.


## 의상 보관함과 배치

**의상 → 보관함**에서 모자·안경·얼굴장식·귀걸이·상의·하의·겉옷·한벌옷 중 분류를 골라 **이미지 추가**를 누릅니다. 로컬 PNG/JPG/BMP/GIF를 앱 보관함에 복사하고 바로 착용합니다. 원본은 수정하지 않습니다. 투명 PNG를 권장하며 GIF는 첫 프레임만 사용합니다. 보관함100개, 동시 착용24개, 파일16MB/가로세로4096px/800만 화소까지입니다.

목록의 이름 버튼을 클릭하면 착용하고 선택합니다. 체크박스로 해제하며 전체/분류 필터로 찾습니다. 얼굴장식과 귀걸이는 여러 개를 함께 착용할 수 있습니다. 나머지는 분류마다 하나입니다. 한벌옷은 상의·하의를 해제하고, 상의나 하의를 입으면 한벌옷을 해제합니다. 겉옷은 두 형태 모두와 함께 입을 수 있습니다.

**의상 → 조정**에서 이름, 크기 비율, X/Y를 변경합니다. 크기는 원본 비율을 유지하며 5~500%입니다. 좌표는 캐릭터512기준이고 숫자로 소수점 위치를 입력하거나 화살표로1씩 이동합니다. 음량으로 의상이 변형되지는 않으며 캐릭터의 대기 움직임과 같이 이동합니다. 앞으로/뒤로는 이미지가 겹치는 순서를 바꿉니다. 목록의 아래 항목이 앞에 표시됩니다. 미리보기와 방송창에 즉시 반영됩니다.

**의상 저장**을 눌러 현재 착용·크기·위치·이름·순서를 유지합니다. 저장하지 않은 조정은 종료하면 이전 저장값으로 돌아갑니다. 이미지 추가와 보관함 삭제는 즉시 목록 전체를 저장하므로 현재 배치도 함께 저장됩니다. 보관함 삭제는 앱의 복사본만 제거합니다. `%LOCALAPPDATA%\VoxPet\Wardrobe`에 이미지와 wardrobe.json을 보관하며 원본 경로는 저장하지 않습니다. 손상 파일은 자동 삭제하지 않고 읽지 못한 항목을 해제합니다.

plan019 일반 앱은 사용자/Windows 세션마다 한 개만 실행됩니다. 다시 실행하면 추가 앱은 종료하고 기존 설정창을 트레이에서 복원합니다. 이전 버전 앱은 이 규칙을 공유하지 않으므로 먼저 종료하세요. 실행파일·방송창·트레이에는 VoxPet 아이콘을 사용합니다. 김태중 개인 자체 서명 패키지는 [인증서 안내](guides/publisher-signing.md#제공된-개인-서명-패키지)를 따릅니다.

## 이미지 조합 세트와 새 화면

좌측 메뉴에서 입력·반응·캐릭터·표정·테스트·의상·액션을 선택합니다. 작은 창에서는 상단 탭으로 전환합니다. 캐릭터 선택은 늘보군과 펠리만 표시합니다.

캐릭터 → 제작 가이드에서 동일 Canvas의 파츠 규칙을 확인하고, 이미지 세트 → 제작 틀 저장으로 합성 예제 PNG와 imageset.json을 받습니다. 외부 그림 도구에서 제자리에 그린 이미지를 준비해 예제를 교체하고 이미지 세트 등록을 누르세요. 액션 → 프레임 액션에서 액션·무기·의상을 고르고 재생합니다. 키 설정 버튼을 누른 뒤 원하는 키를 입력하거나 좌클릭을 켜서 게임에서도 실행할 수 있습니다. 빠른 연타는 첫 프레임부터 다시 시작합니다.

등록은 로컬 보관함에 복사하며 원본을 변경하지 않습니다. 새 파츠 모드에서 기존 의상·손동작 그림은 함께 합성하지 않습니다. 기존 PNG 사용은 선택 캐릭터의 원래 시트를 불러오며 해당 파일이 없으면 현재 세트를 유지하고 안내합니다. 상세 [제작 규격](product/image-set-format.md)을 따릅니다.


## VoxPet 2.0 캐릭터 제작과 관리

**캐릭터**에서 이름 또는 ID로 검색하고, 카드를 고른 뒤 **선택하기**로 방송에 적용합니다. **.voxpet 등록**은 원본을 유지하고 검증된 관리 복사본을 보관합니다. `.voxpet` 카드의 **편집하기**는 원본을 변경하지 않는 편집 문서를 엽니다. **관리 복사본 삭제**는 보관함의 복사본만 지우며 선택 중인 캐릭터를 해제합니다. 기존 PNG 캐릭터는 방송 / 설정에서 관리합니다.

1. **+ 새 캐릭터** 또는 편집기의 **새 캐릭터**로 공개 제작 틀을 엽니다. 기본 정보에서 이름·ID·버전·제작자·설명·Canvas 너비와 높이를 입력하고 **설정 적용**을 누릅니다. 썸네일은 선택 사항입니다.
2. **부위 / 이미지**에서 파츠를 추가하고 PNG 버튼으로 이미지를 준비합니다. ID·유형·앵커·Z-index·표시·위치·배율·회전을 정한 뒤 적용합니다. PNG를 준비한 것만으로 파츠 연결이 바뀌지는 않습니다.
3. **앵커**에서 점을 마우스로 끌거나 부모와 local X/Y를 입력합니다. 부모가 있으면 좌표는 부모 기준입니다. 누락 부모·순환·누락 PNG는 거부하고 마지막 유효 미리보기를 유지합니다.
4. **얼굴 · 입 / 눈**에서1~16입 프레임과 곡선·프레임 위치·blink·대기/음량 반응을 설정합니다. **표정**에서 눈 뜸·눈 감음·눈썹 PNG를 교체합니다. 전체 시트 패키지는 표정 bank를 선택해 각 프레임과 그 표정의 깜빡임을 편집합니다.
5. **동작 · 타임라인**에서 길이(ms)·우선순위·재생/중단/idle복귀를 정합니다. 이벤트 또는 트리거를 추가하고 해당 행을 선택해 **상세 적용**을 누릅니다. 포즈의 교체 PNG에 `숨김`을 고르면 해당 파츠를 숨깁니다. 포즈 변환은 `X,Y,SX,SY,각도`입니다. Sound는 예약 항목으로 재생하지 않습니다.
6. **부착물 · 의상**에서 분류와 레이어를 추가하고 PNG·앵커·위치·크기·회전·각 상속 옵션을 적용합니다. 포즈 PNG 이름은 캐릭터 포즈 이름과 연결합니다. 착용/해제 버튼으로 같은 Runtime의 결과를 확인합니다.
7. **미리보기 / 내보내기**에서 음량을 움직이고 표정·동작·부착물을 시험합니다. 재생은 시간에 따라 진행하고, 타임라인 슬라이더는 선택한 동작의 해당 시점을 정지해서 보여줍니다. **검증**을 통과한 문서를 **.voxpet 내보내기**로 저장합니다. 내보낸 파일을 캐릭터 목록에 등록하면 방송에서 사용합니다.

미적용 입력은 페이지·선택을 바꾸어도 유지하며 내보내기를 막습니다. 해당 설정/상세를 적용하거나 **미적용 입력 취소**로 취소하세요. 추가·삭제 전에 미적용 입력을 정리합니다. 실패한 적용/불러오기는 현재 문서와 미리보기를 유지합니다. 편집 문서는 자동 저장하지 않으므로 종료 전에 내보내세요. 작은 창의 새 화면은 가로·세로 스크롤로 조작합니다. 원본 PNG와 지원 데이터는 편집·내보내기 과정에서 보존됩니다.
