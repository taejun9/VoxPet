VoxPet — 목소리로 움직이는 캐릭터

Windows x64에서 VoxPet.exe 실행. .NET 설치는 필요 없습니다.
마이크를 선택 → Start → 말하기 → Stop 순서로 사용합니다.
처음에는 마이크 없이 데모 버튼으로 캐릭터와 방송창을 확인할 수 있습니다.
설정창은 주 화면의 작업 영역에 맞춰 열고, 좁은 창에서는 한 열 배치로 전환합니다.
마우스 휠/스크롤 막대로 조정값과 미리보기를 볼 수 있습니다.

마이크가 없거나 연결을 바꿨으면 Stop 후 ↻ 새로고침하세요.
Windows 설정 → 개인정보 및 보안 → 마이크에서 데스크톱 앱의 접근을 허용하세요.
마이크는 Start를 누른 뒤에만 사용합니다. 음성은 저장하거나 전송하지 않습니다.
RMS/Peak/dBFS는 상대 입력 레벨이며 실제 음압이나 발화 여부 판정이 아닙니다.

Noise Gate: 높이면 작은 소음에 덜 반응합니다. 큰 키보드 소리는 반응할 수 있습니다.
Sensitivity: 높이면 같은 입력에 입이 더 크게 열립니다.
Attack/Release: 각각 열림/닫힘의 시간 상수입니다. 높일수록 느립니다.
작은 목소리: 입력 반응 범위를 펼쳐 낮은 입력과 Gate를 함께 낮추면 조용한 마이크도 조정할 수 있습니다.
기본값 버튼은 오디오 조정값을 초기화합니다.
Stop/장치 오류/종료 때 이전 음량을 초기화합니다.
종료 지연 안내가 나오면 잠시 후 Stop/앱 종료를 다시 시도하세요.

캐릭터 방송창 열기 → OBS Window Capture에서 VoxPet Character 선택.
캡처 방식은 Windows Graphics Capture(Windows 10 이상 방식)를 먼저 시도하세요.
OBS 32.2.2 합성 데모에서는 WGC가 통과했고 BitBlt는 유효 프레임을 얻지 못했습니다.
초록 배경 + OBS Chroma Key 필터(Green)를 사용할 수 있습니다.
투명 배경은 Windows 창의 투명도이며 OBS alpha 보존을 보장하지 않습니다.
방송창 드래그로 이동, 우측 하단으로 크기 조절, Esc/우클릭 메뉴로 닫기.
설정창을 최소화해도 방송창은 계속 표시됩니다.
방송창만 닫아도 마이크 분석은 계속됩니다. Stop 또는 메인 창 종료로 캡처를 해제하세요.

조정값과 방송창 옵션은 종료 때 %LOCALAPPDATA%\VoxPet\settings.json에 저장합니다.
개인 장치 ID와 음성은 설정에 저장하지 않습니다. 손상된 파일은 기본값으로 복구합니다.
기본 캐릭터는 독자 제작 CC0 자산입니다. 라이선스/출처는 Assets/Characters/manifest.json과 Licenses/에 있습니다.

Windows 11 x64의 지원 중인 버전을 우선 검증합니다.
실제 마이크·권한·장치 제거·OBS·장시간 테스트는 배포 전 확인해야 합니다.
최신 검증 상태와 전체 사용 안내: https://github.com/taejun9/VoxPet/tree/main/docs

추가 편의 기능
- 일반 대화 / 조용한 목소리 / 빠른 반응 버튼으로 반응 설정을 적용합니다.
- 캐릭터 음소거는 입 반응만 멈추며 입력 표시와 마이크 캡처는 계속됩니다. 마이크 해제는 Stop입니다.
- PNG 시트 불러오기: 8비트 RGBA 투명 PNG, 16MB 이하, 셀 128~1024px의 정사각형 3열 x 2행.
  열: 입 닫힘 / 중간 / 열림. 행: 눈 뜸 / 눈 감음. 중앙/바닥 자동 정렬.
  파일 오류 시 기존 캐릭터를 유지합니다. 기본 캐릭터 버튼으로 복원합니다.
  개인 캐릭터 파일 경로와 음소거는 저장하지 않습니다. 재실행 후 다시 선택합니다.
