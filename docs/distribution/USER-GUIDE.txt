VoxPet 사용 설명서 — 목소리로 움직이는 캐릭터

1. 실행과 빠른 시작
Windows x64 배포 ZIP을 폴더에 모두 풀고 VoxPet.exe를 실행하세요.
자체 포함 배포본은 별도 .NET 설치가 필요 없습니다.
Licenses/, Assets/Characters/manifest.json, 이 USER-GUIDE.txt도 함께 보관하세요.
처음에는 [마이크 없이 데모]로 입/눈/몸 반응을 확인하고 [Stop]으로 끝내세요.
마이크 선택 → [Start] → 평소 목소리로 말하기 → [Stop] 순서로 사용합니다.
하단의 분석 중 상태와 RMS/Peak/dBFS 및 VOICE LEVEL을 확인하세요.
앱은 시작할 때 자동으로 마이크 캡처를 시작하지 않습니다.
설정창은 주 화면의 작업 영역에 맞춰 열고 좁거나 낮은 창에서는 탭이 넓어집니다. 캐릭터 탭에서 미리보기를 볼 수 있습니다.
상단 탭으로 조정값과 미리보기를 선택합니다. 작은 창은 내용 크기를 줄여 스크롤 없이 표시합니다.

2. 마이크와 개인정보
마이크가 없거나 연결을 바꿨으면 연결·권한을 확인한 뒤 [↻]로 새로고침하세요.
Windows 설정 → 개인정보 및 보안 → 마이크 → 데스크톱 앱의 마이크 접근을 확인하세요.
장치 교체는 [Stop] → 새 장치 선택 → [Start] 순서입니다.
음성은 로컬 메모리에서만 분석하며 녹음·저장·원격 전송하지 않습니다.
방송창만 닫아도 분석은 계속됩니다. [Stop] 또는 메인 설정창 종료로 캡처를 해제하세요.
종료 지연 안내가 나오면 잠시 후 [Stop] 또는 앱 종료를 다시 시도하세요.

3. 표시값과 반응 조정
VOICE LEVEL: Gate·감도·평활화를 적용한 0~100% 캐릭터 입 반응입니다.
RAW: 입력 범위로 정규화한 값이며 Gate·감도·평활화 적용 전 값입니다.
RMS/Peak/dBFS: full scale 기준의 상대 입력 레벨이며 실제 음압이나 발화 판정이 아닙니다.
Peak가 1 이상이면 CLIP 표시가 나옵니다. Windows 입력 볼륨을 낮춰 확인하세요.
앱의 Sensitivity를 낮춰도 입력 자체의 clipping이 해결되지는 않습니다.

Noise Gate: 기본 -50 dBFS. -50에서 -40으로 높이면 작은 입력을 더 많이 막습니다.
Gate는 음성과 소음을 의미적으로 구별하지 못하며 큰 키보드 소리에도 반응할 수 있습니다.
Sensitivity: 기본 1.0배. 높이면 같은 입력에 입이 더 크게 열립니다. 0이면 입 반응이 사라집니다.
Gate 미만의 입력은 감도를 올려도 반응하지 않습니다.
Attack/Release: 기본 40/140ms. 열림/닫힘의 시간 상수이며 값이 클수록 느립니다.
반응 탭에서 낮은 입력과 Gate를 함께 낮추세요.
낮은 입력/높은 입력: 기본 -50/-10 dBFS. RAW의 0%/100% 기준입니다.
낮은 입력은 높은 입력보다 작아야 하며 교차하면 앱이 상대 경계를 함께 조정합니다.
입 모양은 VOICE LEVEL 20% 미만 닫힘, 20~60% 미만 중간, 60% 이상 열림입니다.
Stop 후 레벨은 0으로 초기화되지만 대기 움직임과 눈 깜빡임은 계속됩니다.

프리셋 (Gate / 낮은·높은 입력 / 감도 / Attack·Release):
- 일반 대화: -50 / -50·-10 dBFS / 1.0배 / 40·140ms
- 조용한 목소리: -65 / -65·-20 dBFS / 1.2배 / 50·180ms
- 빠른 반응: -45 / -45·-10 dBFS / 1.0배 / 15·80ms
[기본값]은 일반 대화의 오디오 조정값을 복원합니다.
[캐릭터 음소거]는 입 반응만 즉시 멈춥니다. RAW/측정값·마이크 캡처·눈 깜빡임은 계속됩니다.
마이크를 해제하려면 [Stop]을 누르세요. 음소거는 재실행 때 유지되지 않습니다.

4. 개인 PNG 캐릭터
[PNG 시트 불러오기]로 로컬 파일을 선택하면 미리보기와 방송창에 함께 적용됩니다.
규격: 16MB 이하의 8비트 RGBA 투명 PNG 하나, 정사각형 셀 3열 x 2행.
셀 한 변은 128~1024px입니다. 예: 셀 512px이면 전체 1536 x 1024px.
첫째 행(눈 뜸): 입 닫힘 / 중간 / 열림
둘째 행(눈 감음): 입 닫힘 / 중간 / 열림
각 셀에는 완전한 캐릭터와 실제 투명 픽셀이 있어야 합니다.
RGB/팔레트 PNG, 빈 셀, 투명 여백 없는 셀은 거부됩니다.
몸 크기를 모든 상태에서 동일하게 맞추세요. 앱은 중앙/바닥 위치를 정렬하며 크기는 바꾸지 않습니다.
오류나 취소 시 기존 캐릭터를 유지합니다. [기본 캐릭터]로 패키지의 기본 캐릭터를 복원하세요. 개인 패키지는 늘보군입니다.
원본 파일은 로딩 후 점유하지 않습니다. 일반 불러오기의 개인 캐릭터와 경로는 저장하지 않으므로 재실행 때 다시 선택하세요.
이용 권리가 있는 파일을 사용하세요. 기본 고양이는 독자 제작 CC0 자산입니다.
출처와 라이선스 고지는 Assets/Characters/manifest.json과 Licenses/에서 확인하세요.

5. OBS 방송창
[캐릭터 방송창 열기] → OBS 소스 추가 → 윈도우 캡처(Window Capture).
대상 창: VoxPet Character. 캡처 방식은 Windows Graphics Capture를 먼저 시도하세요.
초록 배경을 켜고 해당 OBS 소스의 필터 → 크로마 키(Chroma Key) → Green을 적용하세요.
초록색이 포함된 캐릭터는 해당 부분도 지워질 수 있으므로 OBS 미리보기를 확인하세요.
투명 배경은 Windows 창의 투명도이며 사용자 환경의 OBS alpha 보존을 보장하지 않습니다.
OBS 32.2.2 합성 데모에서는 WGC가 통과했고 BitBlt는 유효 프레임을 얻지 못했습니다.
검은 배경이나 빈 화면이면 대상 창/WGC를 확인하고 초록 배경과 크로마 키로 시험하세요.
방송창은 캐릭터 화면을 제공합니다. 목소리 송출은 OBS의 마이크 오디오 소스를 별도로 설정하세요.
방송창 드래그로 이동, 우측 하단으로 크기 조절, Esc/우클릭 메뉴로 닫을 수 있습니다.
설정창을 최소화해도 방송창은 계속 표시됩니다. 두 창은 하나의 마이크 세션을 공유합니다.
메인 설정창을 닫으면 마이크 종료 후 방송창도 닫힙니다.

6. 설정 저장과 문제 해결
조정값과 방송창 항상 위/초록 배경은 정상 종료 때 다음 파일에 저장합니다.
%LOCALAPPDATA%\VoxPet\settings.json
장치 ID, 음성, 개인 PNG 경로, 음소거, 데모 상태는 저장하지 않습니다.
설정이 손상되면 기본값으로 시작합니다. 저장이 안 되면 폴더의 쓰기 권한을 확인하세요.
전체 저장 설정 초기화: 앱 종료 후 settings.json을 다른 이름으로 옮겨 보관하고 재실행하세요.
[기본값]은 오디오 조정값만, [기본 캐릭터]는 이미지 상태만 복원합니다.
Start 비활성: 데모/시작/종료 처리가 끝났는지, 마이크가 선택되었는지 확인하세요.
측정값 0: 분석 중 상태, Windows 입력 장치/볼륨/권한을 확인하세요.
수치는 변하지만 입이 멈춤: 캐릭터 음소거, 감도 0, Gate와 낮은 입력을 확인하세요.
장치 연결 제거: 재연결 → 새로고침 → Start로 복구하세요.

7. 검증 상태와 관련 문서
Windows 11 x64의 지원 중인 버전을 우선 검증합니다.
Windows 자동 빌드·Core 테스트·WPF smoke와 OBS WGC 합성 데모 기록이 있습니다.
실제 마이크·권한·장치 제거·사용자 GPU/OBS·물리 DPI·실제 입력 장시간 시험은 별도 확인 항목입니다.

프로젝트 구조: https://github.com/taejun9/VoxPet/blob/main/README.md

8. 표정 슬롯과 모션
[표정 · 단축키 슬롯]에서 F1~F12 슬롯과 이름을 선택하세요.
기본 표정은 평상/기쁨/슬픔/화남/놀람/졸림이며 F3은 처음에 눈물이 켜져 있습니다.
눈물 탭의 [눈 깜빡임]/[눈물 모션]과 눈물 위치를 조정하고 [표정 미리보기] → [슬롯 저장]을 누르세요.
단축키와 슬롯 버튼은 마지막 저장값을 사용합니다. 저장하지 않은 편집은 미리보기에만 적용됩니다.
Ctrl+Shift+F1~F11: 다른 앱을 사용하거나 설정창이 최소화되어도 전환됩니다.
Ctrl+Shift+F12: Windows 예약 키이므로 VoxPet 설정창/방송창 안에서만 동작합니다.
단축키 등록 실패 안내가 있으면 앱 안의 키 또는 슬롯 버튼을 사용하세요.
다른 앱의 키 점유를 해제한 뒤 VoxPet을 다시 시작하면 등록을 재시도합니다.
전환은 약 240ms 동안 부드럽게 진행하며 연속 입력에서는 최신 요청을 표시합니다.
[슬롯 PNG 선택]으로 표정별 3열 x 2행 RGBA PNG를 선택하고 저장할 수 있습니다.
사용자 시트는 해당 눈/입 그림을 직접 포함해야 합니다. 눈물 위치는 위 슬라이더로 맞추세요.
[내장 표정 사용]은 해당 슬롯의 사용자 시트를 해제합니다. 변경 후 저장하세요.
슬롯 저장은 즉시 %LOCALAPPDATA%\VoxPet\Expressions에 JSON/PNG 복사본을 저장합니다.
원본 파일/경로는 변경·저장하지 않습니다. 복사본은 원본을 이동해도 유지됩니다.
재실행 시 F1 표정을 표시합니다. 일반 [PNG 시트 불러오기]는 계속 현재 실행에만 적용됩니다.
슬롯 JSON 손상은 해당 슬롯만 기본값으로 복구합니다. PNG 손상은 현재 표시를 유지합니다.
복구하려면 해당 슬롯에 정상 PNG 또는 내장 표정을 저장하세요.
전체 표정 초기화는 앱 종료 후 Expressions 폴더를 다른 이름으로 옮겨 보관하세요.
눈 깜빡임/눈물/대기 모션은 Stop/무음/캐릭터 음소거 중에도 계속됩니다.

추가 사용성 기능
- Ctrl+Shift+M: 다른 앱에서도 캐릭터 입 음소거 전환. 충돌 안내 때는 VoxPet 창 내부 키/체크박스 사용.
- 입 음소거는 OBS/Windows 마이크 음소거와 별개이며 마이크 해제는 Stop.
- Start 후 주변 소음 측정 (3초) → 말하지 않고 기다리기 → 추천값 적용 → 목소리 반응 확인.
- 측정 취소/Stop/프리셋은 추천을 취소. 무신호/큰 소음은 추천하지 않으며 기존 값 유지.
- Windows 마이크 권한 설정 열기로 접근 설정 확인. 권한은 사용자가 직접 변경.

상단 설정 탭과 크기 조절
마이크 / 반응 / 캐릭터 / 표정 / 눈물 탭으로 설정을 전환합니다. 스크롤 없이 전체 조작을 표시합니다.
캐릭터 탭의 방송창 너비 / 높이 또는 방송창 우클릭 크기 메뉴로 크기를 바꾸세요.
우하단 모서리 드래그도 사용할 수 있습니다. 범위는 각각 200~1200 DIP, 다음 실행에도 유지합니다.
개인 패키지의 Characters/늘보군.png는 기본 캐릭터로 사용하며 공개 배포에 포함하지 않습니다.
저장된 사용자 PNG 슬롯은 보존하고 마지막 사용한 슬롯/내장 표정을 복원합니다. 이전 설정에 기록이 없으면 F1을 적용합니다. 선택 캐릭터로 복원 버튼은 현재 선택한 캐릭터로 복원합니다.

세부 탭 안내: 마이크 → 입력 / 음소거·권한, 반응 → 음량 / 소음 측정 / 속도 / 입력 범위, 캐릭터 → 미리보기 / 방송창 / PNG, 표정 → 전환 / 편집 / PNG. 눈물 탭은 깜빡임·눈물 위치와 미리보기·저장을 표시합니다.

늘보군 표정과 상세 입 반응 (개인 plan015 패키지)
평상/기쁨/슬픔/화남/놀람/졸림의 실제 얼굴은 표정→전환 또는 Ctrl+Shift+F1~F6으로 바꿉니다.
입은 Gate/입력 범위/감도/Attack·Release를 거친 음량에 따라8단계로 열립니다.
기존3열 시트/사용자 저장 슬롯은 보존합니다. 상세 시트는8열×2행 RGBA(셀128~512px)입니다.
저장한 사용자 PNG가 우선이면 내장 표정 사용 후 슬롯 저장으로 새 늘보군 표정을 적용하세요.
기본 PNG와 늘보군-표정 폴더를 실행 파일과 함께 유지합니다. 개인 PNG는 공개 배포에 포함하지 않습니다.

표정 순서/12종 테스트
제작자: 김태중 (파일 속성의 회사 정보). Windows 실행 경고의 게시자는 디지털 서명으로 확인합니다. 기본 자동 배포본은 인증서 서명이 없으므로 알 수 없는 게시자로 표시될 수 있습니다. 회사 이름 변경만으로 실행 경고의 게시자가 바뀌지는 않습니다.
표정 → 편집에서 슬롯을 고르고 ↑ 위로/↓ 아래로로 순서를 변경합니다. 즉시 저장되며 F1~F12도 새 순서를 따릅니다. PNG/슬롯 내용과 초안은 유지합니다.
표정 → 테스트에서12종 개별 버튼 또는12종 전체 테스트를 누릅니다. 전체 테스트 완료/중지 후 원래 표정으로 돌아옵니다. 입력이 중지되어 있으면 숫자 데모를 잠시 사용하며 실제 마이크를 자동 시작하지 않습니다. 저장한 슬롯은 바꾸지 않습니다.
