# VoxPet 설치 방법 — 처음 사용하는 분을 위한 안내

VoxPet은 **말할 때 화면 속 캐릭터가 입과 몸을 움직이는 프로그램**입니다. 아래 순서대로 파일을 내려받고 실행하면 됩니다. 프로그래밍이나 명령어 입력은 필요 없습니다.

읽는 순서: **설치(현재 문서) → [사용 방법](usage.md) → [설정 방법](settings.md)**

## 1. 준비할 것

- **Windows 11을 사용하는 x64 컴퓨터**: 현재 안내의 기준 환경입니다.
- **마이크**: 노트북 내장 마이크, USB 마이크, 마이크가 달린 헤드셋 등을 선택할 수 있습니다. 마이크가 없어도 데모를 볼 수 있습니다.
- **인터넷과 웹 브라우저**: 프로그램 파일을 내려받을 때 사용합니다.
- **GitHub 계정**: 아래 다운로드 페이지에서 로그인할 때 필요합니다. GitHub는 이 프로젝트의 파일을 보관하는 사이트입니다.

컴퓨터 종류를 모르면 Windows **시작 → 설정 → 시스템 → 정보**를 열어 **시스템 종류**에서 `x64` 표시를 확인하세요. 이 경로는 [Microsoft의 컴퓨터 종류 확인 안내](https://support.microsoft.com/en-gb/windows/experience/compatibility/32-bit-and-64-bit-windows-frequently-asked-questions)를 따릅니다.

Mac에서는 이 Windows 실행 파일을 실행할 수 없습니다. Windows 10이나 ARM 컴퓨터의 호환성은 이 안내에서 보장하지 않습니다.

## 2. 프로그램 파일 내려받기

**이미 실행용 ZIP 파일을 전달받았다면 3번으로 이동하세요.** ZIP은 여러 파일을 하나로 묶어 놓은 압축 파일입니다.

2026년 10월 6일 확인 기준으로, 별도 설치 마법사나 공개 Release 배포본은 없습니다. GitHub의 자동 검증 결과에서 **VoxPet-win-x64** 파일을 받습니다. 이름에 들어간 x64는 이 실행 파일의 컴퓨터 종류를 뜻합니다.

1. 웹 브라우저에서 [VoxPet 다운로드 목록](https://github.com/taejun9/VoxPet/actions/workflows/windows.yml?query=branch%3Amain)을 엽니다.
2. GitHub에 로그인합니다. 계정이 없으면 화면의 **Sign up(가입)**에서 계정을 만든 뒤 로그인합니다.
3. 목록에서 **main** 표시와 **초록색 체크 표시**가 있는 최근 항목의 제목을 클릭합니다. 초록색 체크는 자동 검증이 끝났다는 뜻입니다.
4. 열린 페이지에서 아래로 내려 **Artifacts**를 찾습니다. 이 부분은 다운로드할 결과 파일 목록입니다.
5. **VoxPet-win-x64**를 클릭합니다. 브라우저가 ZIP 파일을 내려받습니다.
6. 브라우저의 다운로드 목록이나 Windows의 **다운로드** 폴더에서 받은 파일을 찾습니다.

2026년 10월 6일에 확인한 [다운로드 가능한 검증 결과 페이지](https://github.com/taejun9/VoxPet/actions/runs/37414425676)도 사용할 수 있습니다. 시간이 지나 파일이 만료되면 위 다운로드 목록에서 최근 성공 항목을 찾으세요.

**받을 항목은 VoxPet-win-x64입니다.** `Windows-QA-evidence`는 검사 결과 파일입니다. 프로젝트 첫 화면의 **Code → Download ZIP**은 개발용 소스 파일을 받는 메뉴이므로 이 설치 순서에서는 사용하지 않습니다.

파일 목록이 안 보이거나 클릭이 안 되면 로그인 상태를 확인하세요. 파일이 만료됐거나 최근 성공 항목에도 실행 파일이 없으면 프로젝트 제공자에게 **“VoxPet Windows 실행용 ZIP 파일을 보내 주세요”**라고 요청하면 됩니다. 직접 코드를 빌드할 필요는 없습니다.

로그인과 파일 만료에 관한 안내는 [GitHub 공식 다운로드 설명](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts?tool=webui)에 있습니다.

## 3. 압축 풀기

1. 내려받은 ZIP 파일 위에서 **마우스 오른쪽 버튼**을 누릅니다.
2. **모두 압축 풀기… / 모두 추출…(Extract All)**를 선택합니다. Windows 표시 언어에 따라 이름이 조금 다를 수 있습니다.
3. 압축을 풀 위치를 확인합니다. 처음에는 제안된 위치를 그대로 사용해도 됩니다.
4. **압축 풀기 / 추출**을 누릅니다.
5. 완료 후 열린 일반 폴더로 들어갑니다. 안에 폴더가 한 겹 더 있으면 열어 **VoxPet.exe**를 찾습니다.

전체 파일을 함께 풀어 주세요. 폴더 안에서 `VoxPet.exe`, `USER-GUIDE.txt`, `Licenses`와 `Assets` 폴더를 확인할 수 있습니다. 실행 파일 하나만 따로 옮기지 말고 **압축을 푼 폴더 전체를 함께 보관**하세요.

압축 파일과 일반 폴더가 헷갈리면, 파일 이름이 `.zip`으로 끝나는 쪽에서 먼저 위 압축 풀기를 진행하세요. 자세한 Windows 조작은 [Microsoft 압축 풀기 안내](https://support.microsoft.com/ko-kr/windows/experience/storage-filemanagement/zip-and-unzip-files)를 참고하세요.

## 4. 프로그램 실행하기

1. 압축을 푼 폴더 안의 **VoxPet.exe**를 두 번 클릭합니다.
2. `VoxPet · 목소리로 움직이는 캐릭터` 창이 열리는지 확인합니다.
3. 고양이 그림과 **Start**, **Stop** 버튼이 보이면 실행된 것입니다.

Windows가 파일 끝의 `.exe`를 숨기면 이름이 **VoxPet**으로만 보일 수 있습니다. 파일의 종류가 **응용 프로그램**인 항목을 여세요.

현재 실행용 배포본에는 필요한 실행 구성요소가 포함되어 있습니다. 별도로 .NET, Visual Studio, Python을 설치할 필요가 없습니다. 설치 마법사를 진행하지 않으므로 다음에도 이 폴더에서 같은 파일을 실행하면 됩니다.

## 5. 마이크 없이 먼저 확인하기

1. **마이크 없이 데모**를 클릭합니다.
2. 몇 초 동안 고양이의 입과 몸이 움직이는지 봅니다. 눈도 가끔 깜빡입니다.
3. **Stop(중지)**을 클릭해 데모를 끝냅니다.

여기까지 되면 파일 다운로드·압축 풀기·실행 확인이 끝났습니다. 데모에서는 마이크를 사용하지 않으며 소리가 재생되지 않습니다. 실제 목소리로 움직이게 하려면 [사용 방법](usage.md)을 따라 하세요.

## 설치 중 막혔을 때

| 상황 | 할 일 |
|---|---|
| 다운로드 페이지에 파일이 없음 | GitHub 로그인 여부를 확인하고 최근 main 성공 항목의 Artifacts에서 VoxPet-win-x64를 찾으세요. |
| 폴더에 VoxPet.exe가 없음 | 실행용 ZIP을 받았는지 확인하세요. 이름이 VoxPet으로만 표시되는 응용 프로그램도 찾아보세요. |
| 파일이 없다는 오류가 나옴 | ZIP을 모두 압축 풀었는지 확인하고 폴더 전체를 다시 풀어 실행하세요. |
| Windows 보안 경고가 나옴 | 다운로드 주소와 파일이 이 프로젝트에서 받은 것인지 확인하세요. 실행 여부를 판단하기 어렵다면 경고 문구를 프로젝트 제공자에게 알려 주세요. |
| Mac에서 파일이 열리지 않음 | Windows용 실행 파일입니다. 위 안내의 Windows 컴퓨터에서 실행하세요. |
| 마이크 목록이 비어 있음 | 프로그램은 실행된 상태입니다. [설정 방법의 마이크 준비](settings.md#1-windows에서-마이크-준비하기)를 확인하세요. |

## 업데이트와 삭제

### 게시자 이름과 실행 경고

plan017부터 `VoxPet.exe` 파일 속성의 **자세히 → 회사**는 **김태중**입니다. 이 항목은 제작자 메타데이터입니다.

Windows 실행 경고에 나오는 게시자는 EXE의 디지털 서명과 인증서 신뢰로 결정됩니다. 서명하지 않은 파일은 회사 이름을 넣어도 **알 수 없는 게시자**로 표시될 수 있습니다. 경고의 게시자까지 김태중으로 표시하려면 그 이름의 코드 서명 인증서로 최종 EXE를 서명하고 해당 PC가 인증서를 신뢰해야 합니다. 자체 서명 인증서는 개인 개발/시험용이며 기본적으로 Windows가 신뢰하지 않습니다. 새 서명 파일도 SmartScreen 평판 경고가 남을 수 있습니다. [Microsoft 코드 서명 안내](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options)를 참고하세요.

기본 자동 빌드는 인증서가 없는 서명되지 않은 파일을 생성합니다. 사용자 PC의 보안 설정이나 인증서 신뢰 저장소를 자동으로 변경하지 않습니다. 서명 인증서의 개인 키/암호를 채팅 또는 공개 저장소로 보내지 마세요.

**업데이트**하려면 앱을 닫고 새 실행용 ZIP을 받은 뒤 **새 폴더에** 모두 압축 풀어 실행하세요. 기존 폴더는 새 버전이 실행되는지 확인할 때까지 보관해도 됩니다. 설정은 별도로 저장되므로 정상 저장된 반응 설정은 다음 실행에서도 사용됩니다.

**프로그램 삭제**는 VoxPet을 닫고 압축을 푼 프로그램 폴더를 삭제하면 됩니다. 개인 PNG는 본인이 보관한 원본 위치에 남습니다. 저장된 반응 설정까지 초기화하려면 [설정 복구 안내](settings.md#7-설정이-저장되는-범위와-초기화)를 참고하세요.

이 문서는 설치 순서를 설명합니다. 실제 마이크·사용자 방송 환경의 남은 검증 항목은 [검증 기록](../quality/windows-checklist.md)에 있습니다.
