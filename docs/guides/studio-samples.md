# 통합 Studio와 의상·동작 샘플

일반 실행은 새 사이드바의 홈·캐릭터·의상/부착물·동작·방송/설정·편집기로 통일했다. 설정과 PNG 캐릭터의 세부 기능도 같은 사이드바와 공통 미리보기 안에서 열리며 별도 이전 화면으로 전환하지 않는다. 방송창은 사용자가 열 때 생성하는 별도 출력 창이다.

## 바로 시험하기

1. 홈의 **의상17종·동작9종 샘플로 시작**을 누른다. 캐릭터 목록의 **테스트 샘플**에서도 선택할 수 있다.
2. 의상/부착물에서 **착용**을 누르면 공통 미리보기에 표시되고 버튼이 **해제**로 바뀐다. 한벌옷은 상의·하의를 해제한다. **모두 해제**로 되돌린다.
3. 동작에서 **재생**을 누른다. 의상을 입은 상태에서도 시험하며 한 번 재생한 뒤 기본 자세로 돌아온다. **동작 중지**도 제공한다.
4. **방송창 열기**로 같은 캐릭터의 출력을 확인한다. **마이크 없이 데모**를 쓰면 음성 입력 없이 입/몸/눈 반응을 확인할 수 있다.
5. 방송/설정에서 마이크·음성 반응·방송 옵션을 조절한다. PNG 캐릭터 선택 시 표정 슬롯·의상 배치·손동작 설정도 같은 화면에서 제공한다.

개인 캐릭터는 원래 목록에서 다시 선택한다. 샘플은 개인 PNG를 변경하지 않는다. 첫 선택 시 버전1.1.0 관리 복사본을 만들고 같은 버전의 반복 선택은 재사용한다. 이전 버전 복사본은 보존하며 캐릭터 목록에서 계속 선택할 수 있다. 번들 샘플 원본은 삭제 버튼으로 지울 수 없으며 편집/내보내기를 통해 개인 작업으로 활용한다. 자동 키/마우스 트리거는 샘플에서 켜지 않는다.

## 포함한 항목

| 분류 | 샘플 |
|---|---|
| 모자 / 안경 / 얼굴 장식 / 귀걸이 | 헬리콥터 모자 (프로펠러 8프레임) / 둥근 안경 / 볼터치 / 별 귀걸이 |
| 상의 / 하의 / 한벌옷 / 신발 | 민트 스웨터 / 남색 반바지 / 멜빵 / 노란 운동화 |
| 겉옷 / 망토 | 코랄 재킷 / 펄럭이는 날개 (6프레임) |
| 머리 / 등 / 손 장식 / 효과 | 리본 / 작은 날개 / 손목 밴드 / 반짝임 |
| 추가 머리 장식 | 단발머리 / 장발머리 / 폭탄머리 |

총14분류·의상17종이다. 헤어는 머리 장식 분류로 한 번에 하나씩 선택하고 헬리콥터 모자와 함께 착용한다. 리본을 선택하면 헤어가 해제된다. 모자와 날개는 착용만 해도 계속 움직이고9종 동작 재생 중에도 반복한다. 미리보기와 방송창은 같은 프레임을 공유한다.

동작9종은 할퀴기·장난감 총·손하트·장난감 칼·마법봉·권총 발사·활쏘기·한손 휘두르기·양손 휘두르기다. 손동작5종과 Gesture/OneHand/TwoHand/Firearm/Bow 템플릿을 모두 포함한다. 상의·한벌옷·겉옷은 관절 연결 격자, 머리·손 장식은 앵커 상속을 시험한다. 새 손가락 작화나 캐릭터 자동 해부 기능은 아니다.

## 파일과 재생성

`Assets/Samples/studio-samples.voxpet`에 character/17개 attachment/9개 action JSON 및50개 PNG (전체78개 파일)를 담았다. `Assets/Samples/LICENSE.txt`는 공개 제작 틀과 새 절차 도형의 CC0 고지다. 개인 자산·음성·외부 다운로드가 없다. `.voxpet`를 별도 캐릭터 등록으로도 불러올 수 있다.

개발용 `harness/scripts/generate_studio_samples.py`는 Pillow로 절차 도형과 패키지를 재생성한다. 앱과 Windows 배포 실행에는 Python/Pillow가 필요 없다. Core는 모든 항목의 로드/왕복/착용/충돌/관절 이동·효과·idle 복귀를 검사하며 Windows QA는 실제 버튼·공통 미리보기·방송창·설정 동선과 화면을 추가 검사한다.

## 모자·날개를 수정하기

캐릭터 목록에서 테스트 샘플을 선택하고 **편집** → **부착물**에서 `hat` 또는 `cape`를 선택한다. 레이어 상세의 **반복 프레임 수**와 **프레임 간격**을 바꾸고 각 **반복 PNG** 옆 PNG 버튼으로 그림을 넣은 뒤 **상세 적용**한다. 프레임 수를 늘려 적용하면 새 PNG 입력칸이 생긴다. 새 칸은 마지막 그림으로 시작하므로 각 칸을 원하는 그림으로 바꾼다. 0은 정지 그림, 반복은2~64프레임과16~10000ms 간격을 지원한다. 기본은 모자80ms, 날개140ms다.

**부착물 착용 / 해제**와 **미리보기 / 동작 재생**으로 확인하고 **.voxpet 내보내기** 후 캐릭터 목록에서 다시 등록한다. 개인 캐릭터로 구분해 계속 사용할 때는 기본 정보에서 ID와 이름을 바꾼 뒤 내보낸다. 원본 샘플과 기존 복사본은 보존된다. 포즈별 PNG를 지정한 레이어는 해당 포즈 그림을 우선한다.
