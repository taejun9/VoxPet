# 통합 Studio와 의상·동작 샘플

일반 실행은 새 사이드바의 홈·캐릭터·의상/부착물·동작·방송/설정·편집기로 통일했다. 설정과 PNG 캐릭터의 세부 기능도 같은 사이드바와 공통 미리보기 안에서 열리며 별도 이전 화면으로 전환하지 않는다. 방송창은 사용자가 열 때 생성하는 별도 출력 창이다.

## 바로 시험하기

1. 캐릭터에서 **늘보군** 또는 **펠리**를 선택한다. 두 캐릭터 모두 의상17종·동작9종이 기본으로 준비된다. 홈의 **선택한 캐릭터의 의상 · 동작 보기** 또는 사이드바 의상/동작에서 바로 사용한다.
2. 의상/부착물에서 **착용**을 누르면 공통 미리보기에 표시되고 버튼이 **해제**로 바뀐다. 한벌옷은 상의·하의를 해제한다. **모두 해제**로 되돌린다.
3. 동작에서 **재생**을 누른다. 의상을 입은 상태에서도 시험하며 한 번 재생한 뒤 기본 자세로 돌아온다. **동작 중지**도 제공한다.
4. **방송창 열기**로 같은 캐릭터의 출력을 확인한다. **마이크 없이 데모**를 쓰면 음성 입력 없이 입/몸/눈 반응을 확인할 수 있다.
5. 방송/설정에서 마이크·음성 반응·방송 옵션을 조절한다. PNG 캐릭터 선택 시 표정 슬롯·의상 배치·손동작 설정도 같은 화면에서 제공한다.

캐릭터의 원래 PNG·표정·입 반응을 유지하고 그 위에 착용한다. 늘보군은 정면 체형, 펠리는 측면 체형과 앞쪽 날개를 고려해 배치를 다르게 했다. 캐릭터를 오갈 때 현재 실행 중의 착용 선택은 각자 유지한다. 의상 선택은 새 실행 때 기본 해제 상태다. 마지막 캐릭터와 기존 설정·표정 파일은 기존 저장 규칙을 따른다.

이전 별도 테스트 인형은 새 캐릭터 카드로 추가하지 않는다. 이전 자동 샘플의 관리 파일은 삭제하지 않으며 목록에서는 숨긴다. 일반 .voxpet 사용자 캐릭터는 계속 등록/선택/편집할 수 있다. 자동 키/마우스 트리거는 샘플 때문에 새로 활성화하지 않는다.

## 포함한 항목

| 분류 | 샘플 |
|---|---|
| 모자 / 안경 / 얼굴 장식 / 귀걸이 | 헬리콥터 모자 (프로펠러 8프레임) / 둥근 안경 / 볼터치 / 별 귀걸이 |
| 상의 / 하의 / 한벌옷 / 신발 | 민트 스웨터 / 남색 반바지 / 멜빵 / 노란 운동화 |
| 겉옷 / 망토 | 코랄 재킷 / 펄럭이는 날개 (6프레임) |
| 머리 / 등 / 손 장식 / 효과 | 리본 / 작은 날개 / 손목 밴드 / 반짝임 |
| 추가 머리 장식 | 단발머리 / 장발머리 / 폭탄머리 |

총14분류·의상17종이다. 헤어는 머리 장식 분류로 한 번에 하나씩 선택하고 헬리콥터 모자와 함께 착용한다. 리본을 선택하면 헤어가 해제된다. 모자와 날개는 착용만 해도 계속 움직이고9종 동작 재생 중에도 반복한다. 미리보기와 방송창은 같은 프레임을 공유한다.

동작9종은 할퀴기·장난감 총·손하트·장난감 칼·마법봉·권총 발사·활쏘기·한손 휘두르기·양손 휘두르기다. 손동작5종과 Gesture/OneHand/TwoHand/Firearm/Bow 템플릿을 모두 포함한다. 상의·한벌옷·겉옷은 관절 연결 격자, 머리·손 장식은 앵커 상속을 시험한다. 새 손가락 작화나 캐릭터 자동 해부 기능은 아니다.

## 파일과 재생성

`Assets/Samples/companion-neulbo.voxpet`와 `companion-pelly.voxpet`는 개인 캐릭터 그림을 포함하지 않는 의상·동작 자료다. 각각17부착물/9동작과 큰 썸네일을 담는다. 앱은 선택한 로컬 PNG에 이를 연결한다. 원본 PNG·표정/저장 슬롯을 덮어쓰지 않는다.

니트·카디건·멜빵·반바지·운동화·헤어·회전 모자·깃털 날개·주요 소품은 내장 imagegen으로 새로 제작하고 작은 장식은 곡선/음영 자산으로 다듬었다. [제작 기록](../art/companion-samples.md)에 프롬프트와 원본/재생성 명령을 보존한다. 앱 실행에는 Node/Python이 필요 없다. 과거 `studio-samples.voxpet`는 native/편집 호환 회귀용 공개 fixture로 유지하며 일반 화면에서 별도 인형으로 선택하지 않는다.

## 모자·날개를 수정하기

늘보군/펠리를 선택하고 의상/부착물의 **의상 · 동작 편집** → **부착물**에서 `hat` 또는 `cape`를 선택한다. 레이어 상세의 **반복 프레임 수**와 **프레임 간격**을 바꾸고 각 **반복 PNG** 옆 PNG 버튼으로 그림을 넣은 뒤 **상세 적용**한다. 프레임 수를 늘려 적용하면 새 PNG 입력칸이 생긴다. 새 칸은 마지막 그림으로 시작하므로 각 칸을 원하는 그림으로 바꾼다. 0은 정지 그림, 반복은2~64프레임과16~10000ms 간격을 지원한다. 기본은 모자80ms, 날개140ms다.

**부착물 착용 / 해제**와 **미리보기 / 동작 재생**으로 확인하고 **.voxpet 내보내기** 후 캐릭터 목록에서 다시 등록한다. 개인 캐릭터로 구분해 계속 사용할 때는 기본 정보에서 ID와 이름을 바꾼 뒤 내보낸다. 편집 자료는 현재 캐릭터의 현재 표정 시트와 의상·동작을 메모리에서 묶는다. 내보낸 .voxpet에는 개인 그림이 포함되므로 공개 공유 전에 확인한다. 편집 결과는 내보낸 파일로 저장하며, 기본 의상을 다시 생성하거나 원본 PNG를 바꾸지 않는다. 포즈별 PNG를 지정한 레이어는 해당 포즈 그림을 우선한다.
