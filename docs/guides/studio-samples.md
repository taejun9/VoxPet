# 통합 Studio와 의상·동작 샘플

일반 실행은 새 사이드바의 홈·캐릭터·표정·의상/부착물·동작·방송/설정·편집기로 통일했다. 설정과 PNG 캐릭터의 세부 기능도 같은 사이드바와 공통 미리보기 안에서 열리며 별도 이전 화면으로 전환하지 않는다. 방송창은 사용자가 열 때 생성하는 별도 출력 창이다.

## 바로 시험하기

1. 캐릭터에서 **늘보군** 또는 **펠리**를 선택한다. 두 캐릭터 모두 의상17종·동작9종이 기본으로 준비된다. 홈의 **선택한 캐릭터의 의상 · 동작 보기** 또는 사이드바 의상/동작에서 바로 사용한다.
2. 의상/부착물 위쪽 **헤어스타일**에서 단발·장발·폭탄머리를 바로 선택한다. **의상 분류**에서 전체 또는14개 분류를 선택한다. 나머지 의상에서 **착용**을 누르면 공통 미리보기에 표시되고 버튼이 **해제**로 바뀐다. 한벌옷은 상의·하의를 해제한다. **모두 해제**로 되돌린다.
3. 동작에서 **장착 무기 선택**으로 무기를 고른다. **무기 항상 들고 있기**를 켜면 대기 중에도 들고, 끄면 무기 동작 중에만 표시한다. **없음**은 즉시 해제한다. **재생**을 누른다. 의상을 입은 상태에서도 시험하며 한 번 재생한 뒤 기본 자세로 돌아온다. **동작 중지**도 제공한다.
4. **방송창 열기**로 같은 캐릭터의 출력을 확인한다. **마이크 없이 데모**를 쓰면 음성 입력 없이 입/몸/눈 반응을 확인할 수 있다.
5. **표정** 사이드바에서 저장한 F1~F12 슬롯·기본12종 미리보기·전체 테스트를 바로 사용한다. **슬롯 편집 / PNG 등록**도 같은 사이드바 안에서 연다. 등록한 native 캐릭터는 해당 캐릭터의 표정 버튼을 제공한다.
6. 방송/설정에서 마이크·음성 반응·방송 옵션을 조절한다. PNG 캐릭터 선택 시 표정 슬롯·의상 배치·손동작 설정도 같은 화면에서 제공한다.

원본 PNG는 보존하며 앱 안에서 머리·몸통·양팔/날개·양다리의6파츠로 분리해 표시한다. 상의/겉옷의 몸통과 양소매, 하의/신발의 좌우 부분을 각 파츠의 관절에 연결한다. 관절 경계는 원본의 같은 픽셀을6px 겹친다. 늘보군의 어깨는 몸통 앵커를 따르고 손목으로 갈수록 손목 앵커의 영향을 늘려 피부와 소매가 같은 격자로 이어진다. 펠리의 넓은 날개는 회전하는 어깨 축에 맞춰 길이 방향으로 접혀 깃털 안쪽이 뒤집히지 않는다. 원래 표정·입·눈 반응은 분리된 머리에서 유지한다. 입을 벌려 부리 너비가 달라져도 아래 몸통을 기준으로 머리 위치를 맞춘다. 늘보군은 정면 체형, 펠리는 측면 체형·부리·앞쪽 날개를 고려한 조끼와 측면 전용 헤어를 쓴다. 신발을 착용하면 원래 발 파츠를 대체하고 해제하면 복원한다. 캐릭터를 오갈 때 현재 실행 중의 착용 선택은 각자 유지한다. 같은 분류의 기존 추가 의상은 샘플 착용 중 잠시 숨기고 샘플을 해제하면 다시 표시한다. 기존 의상의 저장된 착용 선택을 바꾸지 않는다. 의상 선택은 새 실행 때 기본 해제 상태다. 마지막 캐릭터와 기존 설정·표정 파일은 기존 저장 규칙을 따른다.

이전 별도 테스트 인형은 새 캐릭터 카드로 추가하지 않는다. 이전 자동 샘플의 관리 파일은 삭제하지 않으며 목록에서는 숨긴다. 일반 .voxpet 사용자 캐릭터는 계속 등록/선택/편집할 수 있다. 자동 키/마우스 트리거는 샘플 때문에 새로 활성화하지 않는다.

## 포함한 항목

| 분류 | 샘플 |
|---|---|
| 모자 / 안경 / 얼굴 장식 / 귀걸이 | 헬리콥터 모자 (프로펠러 8프레임) / 둥근 안경 / 볼터치 / 별 귀걸이 |
| 상의 / 하의 / 한벌옷 / 신발 | 민트 스웨터 / 남색 반바지 / 멜빵 / 노란 운동화 |
| 겉옷 / 망토 | 코랄 재킷 / 펄럭이는 날개 (6프레임) |
| 머리 / 등 / 손 장식 / 효과 | 리본 / 작은 날개 / 손목 밴드 / 반짝임 |
| 추가 머리 장식 | 단발머리 / 장발머리 / 폭탄머리 |

총14분류·의상17종이다. 헤어는 머리 장식 분류로 한 번에 하나씩 선택하고 헬리콥터 모자와 함께 착용한다. 리본을 선택하면 헤어가 해제된다. 모자와 날개는 착용만 해도 계속 움직이고9종 동작 재생 중에도 반복한다. 미리보기와 방송창은 같은 프레임을 공유한다.

동작9종은 법규·장난감 총·손하트·장난감 칼·마법봉·권총 발사·활쏘기·한손 휘두르기·양손 휘두르기다. 손동작5종과 Gesture/OneHand/TwoHand/Firearm/Bow 템플릿을 모두 포함한다. 상의·겉옷의 소매는 팔 연결 격자, 한벌옷의 하단은 양다리, 머리 장식은 머리 앵커, 손목 밴드는 팔 격자를 따라 움직인다. 법규는 새 손가락 그림으로 표시한다. 분리는 두 기본 캐릭터의 체형에 맞춘 영역을 사용한다. 임의 그림의 자동 해부는 지원하지 않는다.

무기7개는 서로 다른 그림과 손잡이 위치를 사용한다. 총은 조준→발사 섬광→짧은 반동→회복을 두 번 재생하고, 검은 준비→스윙→마무리→복귀한다. 양손 무기는 두 번째 주먹이 긴 손잡이를 따르고, 활은 왼손으로 잡고 오른손으로 시위를 당겨 화살을 놓는다. 손/날개의 접힌 파지 그림이 손잡이 앞을 덮는다. 새 동작은 키 사이에서 속도가 이어지는 곡선을 사용한다. 늘보군은 느긋한 준비와 부드러운 몸통 탄성·고개 여운, 펠리는 짧은 준비와 날개/고개의 가벼운 뒤따름을 사용한다. 끝의 작은 반동을 거쳐 정확한 대기 자세로 돌아간다. 양손과 활의 손 접점은 유지한다. 기존 native 타임라인은 지정하지 않으면 기존 step 동작을 유지한다.

무기는 장난감 총·장난감 칼·마법봉·권총·활·한손/양손 무기7개다. 캐릭터별 선택과 항상 들기는 자동 저장되어 재시작해도 유지한다. 무기 동작 카드를 누르면 해당 무기를 선택하며 항상 들기 값은 유지한다. 법규/손하트 동안은 손 그림과 겹치지 않게 무기를 잠시 숨긴다. 설정 파일은 `%LOCALAPPDATA%/VoxPet/companion-equipment.json`이다.

## 파일과 재생성

`Assets/Samples/companion-neulbo.voxpet`와 `companion-pelly.voxpet`는 개인 캐릭터 그림을 포함하지 않는 의상·동작 자료다. 각각17부착물/9동작과 큰 썸네일을 담는다. 앱은 선택한 로컬 PNG에 이를 연결한다. 원본 PNG·표정/저장 슬롯을 덮어쓰지 않는다.

니트·카디건·멜빵·반바지·운동화·헤어·회전 모자·깃털 날개·주요 소품은 내장 imagegen으로 새로 제작하고 작은 장식은 곡선/음영 자산으로 다듬었다. [제작 기록](../art/companion-samples.md)에 프롬프트와 원본/재생성 명령을 보존한다. 앱 실행에는 Node/Python이 필요 없다. 과거 `studio-samples.voxpet`는 native/편집 호환 회귀용 공개 fixture로 유지하며 일반 화면에서 별도 인형으로 선택하지 않는다.

## 모자·날개를 수정하기

늘보군/펠리를 선택하고 의상/부착물의 **의상 · 동작 편집** → **부착물**에서 `hat` 또는 `cape`를 선택한다. 레이어 상세의 **반복 프레임 수**와 **프레임 간격**을 바꾸고 각 **반복 PNG** 옆 PNG 버튼으로 그림을 넣은 뒤 **상세 적용**한다. 프레임 수를 늘려 적용하면 새 PNG 입력칸이 생긴다. 새 칸은 마지막 그림으로 시작하므로 각 칸을 원하는 그림으로 바꾼다. 0은 정지 그림, 반복은2~64프레임과16~10000ms 간격을 지원한다. 기본은 모자80ms, 날개140ms다.

**부착물 착용 / 해제**와 **미리보기 / 동작 재생**으로 확인하고 **.voxpet 내보내기** 후 캐릭터 목록에서 다시 등록한다. 개인 캐릭터로 구분해 계속 사용할 때는 기본 정보에서 ID와 이름을 바꾼 뒤 내보낸다. 편집 자료는 현재 캐릭터에서 실제로 분리한6개의512px 투명 PNG와 입/눈별 머리 PNG, 의상·동작을 메모리에서 묶는다. 부위/이미지에서 분리 파츠를 각각 선택하고 바꿀 수 있다. 어깨/손목 경계는 팔과 소매에 같은 값을 쓰며 내보내기·재등록 후에도 보존된다. 내보낸 .voxpet에는 개인 그림이 포함되므로 공개 공유 전에 확인한다. 편집 결과는 내보낸 파일로 저장하며, 기본 의상을 다시 생성하거나 원본 PNG를 바꾸지 않는다. 포즈별 PNG를 지정한 레이어는 해당 포즈 그림을 우선한다.


대기 중에는 작은 호흡과 고개 움직임이 이어지고 말할 때는 음량 변화의 관성에 따라 반응한다. 발 위치는 유지한다. 동작을 중지하거나 다른 동작을 누르면 현재 자세에서 약220ms에 걸쳐 연결한다. 기본 좌클릭·전역 키·항상/간격 설정도 같은 캐릭터 동작을 사용한다. 입은 상세 시트에서15단계(3열 시트는5단계), 깜빡임은4단계의 원본 색상 보간으로 표시한다. 첫 준비는 작업 스레드에서 하며 원본 파일을 바꾸지 않는다. 의상 편집 후 내보내기·재등록해도 캐릭터의 기본 움직임 선택을 유지한다.
