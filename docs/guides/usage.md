# VoxPet 사용 방법 — 버튼을 누르는 순서대로

이 문서는 VoxPet 창이 열린 상태부터 설명합니다. 아직 설치하지 않았다면 [설치 방법](installation.md)을 먼저 따라 하세요.

읽는 순서: [설치 방법](installation.md) → **사용(현재 문서)** → [설정 방법](settings.md)

## 1. 처음에는 이 순서만 따라 하세요

1. 마이크를 컴퓨터에 연결합니다. 노트북 내장 마이크를 쓰면 별도 연결은 필요 없습니다.
2. 상단 **마이크** 탭의 **마이크** 아래 긴 선택 상자를 클릭합니다.
3. 사용할 마이크 이름을 클릭합니다. 어떤 이름인지 모르겠다면 [마이크 확인 방법](settings.md#1-windows에서-마이크-준비하기)을 보세요.
4. **Start(시작)**를 클릭합니다.
5. 하단에 **분석 중**과 선택한 마이크 이름이 나타나는지 확인합니다.
6. 평소 목소리로 “안녕하세요”라고 말하고 잠시 멈춰 봅니다.
7. 말할 때 입이 열리고 멈추면 닫히는지 확인합니다.
8. 끝나면 **Stop(중지)**을 클릭합니다. 하단에 중지 안내가 나오고 입 반응 표시가 0으로 돌아가는지 확인합니다.

**Start는 마이크 분석 시작, Stop은 마이크 사용 중지**입니다. 앱을 열기만 하면 마이크 분석이 자동으로 시작되지 않습니다. VoxPet은 목소리 크기로 캐릭터를 움직이며 음성을 저장하거나 전송하지 않습니다.

## 2. 화면의 어느 부분을 보면 되나요?

| 화면에서 보이는 것 | 쉬운 뜻 |
|---|---|
| 캐릭터 그림 | 목소리에 반응하는 모습입니다. |
| VOICE LEVEL과 막대 | 입이 얼마나 크게 반응하는지를 보여 줍니다. 말하면 올라가고 침묵하면 내려갑니다. |
| 마이크 선택 상자 | 사용할 입력 장치를 고르는 곳입니다. |
| ↻ 버튼 | 마이크 목록을 다시 읽는 버튼입니다. 새 장치를 연결한 뒤 누릅니다. |
| Start / Stop | 마이크 분석을 시작하거나 멈춥니다. |
| 마이크 없이 데모 | 실제 마이크 없이 움직이는 예시를 보여 줍니다. |
| 반응 조정 | 내 목소리에 맞게 움직임을 바꾸는 곳입니다. |
| 창 맨 아래 안내 | 준비·분석 중·중지·오류 상태를 알려 줍니다. |

`RAW`, `RMS`, `Peak`, `dBFS`는 입력 크기를 확인하는 숫자입니다. 처음에는 이 수치를 이해하지 않아도 됩니다. **캐릭터가 움직이는지와 하단 안내**부터 확인하세요.

상단 **마이크 / 반응 / 캐릭터 / 표정 / 눈물** 탭을 눌러 설정을 전환합니다. 값은 탭을 옮겨도 유지됩니다. 작은 창에서는 내용 크기를 줄여 스크롤 없이 표시하며, 캐릭터 미리보기는 **캐릭터** 탭에서도 볼 수 있습니다.

## 3. 내 목소리에 반응 맞추기

1. **반응** 탭의 **반응 조정**에서 **일반 대화**를 클릭합니다.
2. 평소 목소리로 말해 보고 잠깐 침묵합니다.
3. 목소리가 작아 반응이 약하면 **조용한 목소리**를 클릭합니다.
4. 입이 더 빠르게 열리고 닫히길 원하면 **빠른 반응**을 클릭합니다.

프리셋은 여러 값을 한꺼번에 맞춰 주는 버튼입니다. 처음에는 이 세 버튼으로 비교하면 됩니다. 더 자세히 바꾸려면 [설정 방법](settings.md)을 읽으세요.

## 4. 잠깐 멈추기와 마이크 바꾸기

### 마이크 사용을 잠깐 중지할 때

**Stop**을 누르세요. 다시 사용할 때는 **Start**를 누릅니다. 중지해도 캐릭터의 눈 깜빡임과 가벼운 대기 움직임은 계속될 수 있습니다.

### 캐릭터의 입 반응만 멈출 때

**캐릭터 음소거** 옆 네모 칸을 클릭해 체크합니다. 입 반응과 VOICE LEVEL이 0이 됩니다. 다시 클릭해 체크를 풀면 현재 입력에 반응합니다.

**캐릭터 음소거를 켜도 마이크는 계속 사용됩니다.** 입력 숫자도 계속 바뀝니다. 마이크 사용 자체를 멈추려면 Stop을 누르세요. OBS 등 다른 프로그램의 마이크 소리도 별도로 제어해야 합니다.

### 다른 마이크로 바꿀 때

1. **Stop**을 클릭합니다.
2. 필요한 마이크를 연결합니다.
3. **↻**를 클릭합니다.
4. 선택 상자에서 새 마이크 이름을 고릅니다.
5. **Start**를 클릭합니다.

마이크 선택이 회색으로 보이면 실행 중인 데모나 마이크 분석을 Stop으로 끝내고 종료 안내를 기다리세요.

## 5. 캐릭터만 보이는 창 열기

1. **캐릭터 방송창 열기 ↗**를 클릭합니다.
2. `VoxPet Character`라는 별도 창이 열립니다. 조정 버튼 없이 캐릭터만 보이는 창입니다.
3. 캐릭터나 배경을 마우스 왼쪽 버튼으로 누른 채 끌면 창이 이동합니다.
4. **캐릭터** 탭의 **방송창 너비 / 높이** 슬라이더로 크기를 바꿀 수 있습니다. 방송창의 오른쪽 아래 모서리를 끌거나 우클릭 메뉴에서 320 / 480 / 640 크기를 선택해도 됩니다. 너비와 높이는 각각 200~1200 DIP이며 캐릭터 비율은 유지됩니다. 이번 실행에서 방송창을 닫고 다시 열어도 크기를 유지합니다.
5. 창을 닫으려면 그 창을 클릭한 뒤 키보드 **Esc**를 누릅니다. 또는 창 안에서 오른쪽 클릭 → **방송창 닫기 (Esc)**를 선택합니다.

설정창을 최소화해도 방송창은 계속 표시됩니다. 방송창을 다시 열려면 같은 열기 버튼을 누르세요.

**방송창만 닫아도 마이크 분석은 계속됩니다.** 마이크를 멈추려면 설정창의 Stop을 누르세요. OBS에 캐릭터를 넣는 방법은 [방송 설정](settings.md#6-obs에-캐릭터-넣기-방송하는-분만)을 참고하세요.

## 6. 내 캐릭터로 바꾸기

기본 공개 앱은 내장 고양이로 시작합니다. 개인 늘보군 패키지는 실행 폴더의 `Characters/늘보군.png`를 기본 캐릭터로 사용합니다. 기존에 F1 슬롯에 저장한 사용자 PNG가 있으면 그 슬롯을 우선 표시합니다. 준비된 캐릭터 시트 파일이 있다면 다음 순서로 바꿉니다.

1. **캐릭터** 탭의 **PNG 시트 불러오기**를 클릭합니다.
2. 파일 선택 창에서 준비된 PNG 파일을 선택하고 **열기**를 누릅니다.
3. **캐릭터 적용 완료** 안내와 그림이 바뀌었는지 확인합니다.
4. **마이크 없이 데모**로 입과 눈의 움직임을 확인합니다. 이미 마이크 분석 중이면 그대로 말해 확인해도 됩니다.

PNG는 이미지 파일의 한 종류입니다. 이 앱에서는 여섯 표정을 한 장에 넣은 **시트**가 필요하므로 일반 사진 한 장을 그대로 사용할 수는 없습니다. 파일 준비 방법은 [캐릭터 설정](settings.md#5-내-캐릭터-설정-선택-사항)에 있습니다.

잘못된 파일을 선택하거나 취소하면 기존 캐릭터가 유지됩니다. **기본 캐릭터**를 누르면 해당 패키지의 기본 캐릭터로 돌아옵니다(개인 패키지는 늘보군). 일반 불러오기는 다음 실행에 다시 선택해야 합니다. 표정 슬롯에 저장하면 관리 복사본이 유지됩니다.

## 7. 프로그램 끝내기와 다음 실행

1. **Stop**을 눌러 중지 안내를 확인합니다.
2. 메인 설정창 오른쪽 위의 **×**를 클릭합니다.
3. 설정창과 방송창이 닫히는지 확인합니다.

설정창을 바로 닫아도 앱은 마이크 종료를 먼저 처리합니다. 종료가 지연된다는 안내가 나오면 잠시 기다린 뒤 Stop이나 닫기를 다시 시도하세요.

다음에는 설치 때 압축을 푼 폴더의 **VoxPet.exe**를 다시 엽니다. 마이크를 고르고 Start를 누르면 됩니다. 정상 종료 때 반응 조정과 방송창 옵션이 저장되며 일반 불러오기 캐릭터와 캐릭터 음소거는 저장되지 않습니다. 표정 슬롯은 저장 버튼을 누른 값이 유지됩니다.

## 사용 중 막혔을 때

| 상황 | 먼저 해볼 일 |
|---|---|
| Start를 누를 수 없음 | 데모를 Stop으로 끝내고 마이크가 선택됐는지 확인하세요. |
| 마이크 이름이 안 보임 | 연결 후 ↻를 누르고 [Windows 마이크 설정](settings.md#1-windows에서-마이크-준비하기)을 확인하세요. |
| 말해도 입이 안 움직임 | 하단이 분석 중인지 확인하고 캐릭터 음소거를 해제한 뒤 조용한 목소리를 눌러 보세요. |
| 아무 말도 안 했는데 입이 열림 | [Noise Gate 조정](settings.md#3-반응을-조금씩-조정하기)을 따라 해보세요. 주변 소리도 입력으로 감지됩니다. |
| 마이크를 뽑은 뒤 오류가 남음 | 다시 연결하고 종료 처리가 끝나면 ↻ → 마이크 선택 → Start 순서로 재시작하세요. |
| 버튼이 안 보임 | 상단 탭에서 해당 설정을 선택하세요. 글씨가 작으면 창을 크게 하세요. |
| 설정을 바꾼 뒤 이상해짐 | 반응 조정의 기본값을 눌러 다시 시작하세요. |

해결되지 않으면 **어떤 버튼을 눌렀는지, 하단에 어떤 안내가 떴는지, 데모는 움직이는지**를 프로젝트 제공자에게 알려 주세요. 목소리 녹음이나 개인 정보를 보낼 필요는 없습니다.

## 저장한 표정으로 바꾸기

처음부터 Ctrl+Shift+F1 평상, F2 기쁨, F3 눈물 나는 슬픔, F4 화남, F5 놀람, F6 졸림을 사용할 수 있습니다. 상단 **표정** 탭의 **표정 · 단축키 슬롯**의 버튼으로도 전환됩니다. F7~F12는 직접 설정해 저장할 수 있습니다.

표정은 부드럽게 전환하며 눈 깜빡임과 눈물은 말을 하지 않아도 움직입니다. F1~F11 단축키는 다른 앱에서도, F12는 VoxPet 창을 클릭한 상태에서 사용할 수 있습니다. 표정이나 PNG를 바꾸려면 [표정 설정](settings.md#표정단축키와-눈물-설정)을 읽으세요.

## 방송 중 단축키로 입 음소거하기

**Ctrl+Shift+M**을 누르면 캐릭터 입 음소거를 켜거나 끕니다. 다른 앱을 사용하는 중이거나 설정창을 최소화해도 전역 키가 등록되어 있으면 동작합니다. 등록에 실패하면 화면에 안내하며 VoxPet 설정창/방송창을 클릭하고 같은 키를 누르거나 **캐릭터 음소거** 체크박스를 사용하세요.

입만 멈추므로 마이크 입력과 RAW 표시, 눈 깜빡임은 계속됩니다. OBS/Windows 음소거와 자동으로 연결되지 않습니다. 마이크를 완전히 해제하려면 **Stop**을 누르세요. 음소거 상태는 재시작 때 유지되지 않습니다.

세부 탭 안내: 마이크 → 입력 / 음소거·권한, 반응 → 음량 / 소음 측정 / 속도 / 입력 범위, 캐릭터 → 미리보기 / 방송창 / PNG, 표정 → 전환 / 편집 / PNG. 눈물 탭은 깜빡임·눈물 위치와 미리보기·저장을 표시합니다.


## 늘보군 표정과 상세 입 반응

개인 plan015 패키지는 평상·기쁨·슬픔·화남·놀람·졸림의 서로 다른 늘보군 얼굴을 포함합니다. 표정→전환에서 F1~F6 버튼을 누르거나 Ctrl+Shift+F1~F6을 사용하세요. 기본 표정을 선택하고 미리보기/저장해 다른 슬롯에도 적용할 수 있습니다. 이전에 저장한 사용자 PNG는 그대로 보존합니다. 해당 슬롯을 새 늘보군 얼굴로 바꾸려면 표정→편집에서 종류를 선택하고 표정→PNG의 내장 표정 사용 후 슬롯 저장을 누릅니다.

입은 닫힘부터 최대 열림까지8단계로 반응합니다. RAW dBFS가 Gate·입력 범위·감도·Attack/Release를 거친0~1 반응값에 따라 바뀌므로 고정된 절대 데시벨 표가 아닙니다. 실제 목소리를 듣거나 감정을 판별하지 않습니다. 조용한 목소리가 잘리지 않게 Gate/입력 범위를 맞추고 감도를 조절하세요. 무음·Stop·입 음소거는 입을 닫으며 깜빡임과 눈물은 독립적으로 동작합니다.

기존3열×2행 PNG/저장 슬롯은 계속 지원합니다. 상세 PNG는 정사각형 셀8열×2행이며 위쪽은 눈 뜸, 아래쪽은 눈 감음, 왼쪽부터 입이 점차 커집니다. 상세 셀은128~512px, 기존3열은128~1024px, 파일은16MB 이하8비트 RGBA입니다. 기본 파일은 Characters/늘보군.png, 표정별 파일은 Characters/늘보군-표정/happy.png, sad.png, angry.png, surprised.png, sleepy.png입니다. 표정 파일이 잘못되거나 없으면 평상 시트를 사용하며 기존 설정을 삭제하지 않습니다. 개인 자산은 공개 Git/CI에 포함하지 않습니다.
