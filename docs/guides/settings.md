# VoxPet 설정 방법 — 내 목소리에 맞추기

처음에는 **마이크 권한 확인 → 일반 대화 또는 조용한 목소리 선택**까지만 하면 됩니다. 나머지는 필요한 항목만 읽으세요.

이 문서는 Windows 11 화면을 기준으로 합니다. 표시 언어와 Windows 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.

이전 단계: [설치 방법](installation.md) · [사용 방법](usage.md)

## 1. Windows에서 마이크 준비하기

### 마이크 사용 권한 켜기

VoxPet의 **Windows 마이크 권한 설정 열기** 버튼으로 이 설정 페이지를 바로 열 수 있습니다. 버튼은 접근 권한을 자동으로 변경하지 않습니다. 열리지 않으면 아래 순서로 직접 이동하세요.

1. Windows 화면 아래의 **시작 버튼**을 클릭합니다.
2. **설정**을 엽니다.
3. **개인정보 및 보안 → 마이크**로 이동합니다.
4. **마이크 액세스**와 **앱에서 마이크에 액세스하도록 허용**이 켜져 있는지 확인합니다.
5. 아래로 내려 **데스크톱 앱에서 마이크에 액세스하도록 허용**을 켭니다.
6. VoxPet으로 돌아와 **↻**를 누르고 마이크를 고른 뒤 **Start**를 누릅니다.

VoxPet은 데스크톱 앱입니다. Store 앱별 목록에서 VoxPet을 찾기보다 데스크톱 앱의 접근 항목을 확인하세요. 자세한 경로는 [Microsoft 마이크 권한 안내](https://support.microsoft.com/ko-kr/windows/privacy/turn-on-app-permissions-for-your-microphone-in-windows)에 있습니다.

### 어떤 마이크를 골라야 하는지 모를 때

1. Windows **시작 → 설정 → 시스템 → 소리**를 엽니다.
2. **입력** 항목에서 사용할 마이크 이름을 확인합니다. USB 마이크나 헤드셋은 연결한 제품 이름으로 보일 수 있습니다.
3. 마이크에 물리적인 음소거 버튼이 있다면 꺼져 있는지 확인합니다.
4. VoxPet으로 돌아가 같은 마이크 이름을 선택합니다.

소리가 지나치게 작거나 `CLIP`이 자주 보이면 Windows 소리 설정에서 해당 마이크를 선택해 **입력 볼륨**을 조절하세요. CLIP은 입력이 너무 커서 소리가 찌그러질 수 있다는 표시입니다. Windows의 입력 볼륨은 다른 프로그램에도 영향을 줄 수 있습니다. [Microsoft 마이크 문제 해결 안내](https://support.microsoft.com/en-us/windows/hardware/drivers/fix-microphone-problems)를 참고하세요.

## 2. 가장 쉬운 설정: 프리셋 버튼

마이크를 선택하고 Start를 누른 상태에서 **반응** 탭의 **반응 조정**의 버튼을 하나씩 시험하세요.

| 버튼 | 이런 때 눌러 보세요 |
|---|---|
| 일반 대화 | 평소 목소리로 시작할 때 |
| 조용한 목소리 | 작은 목소리에 입이 잘 안 열릴 때 |
| 빠른 반응 | 짧은 말에도 입이 빠르게 열리고 닫히길 원할 때 |
| 기본값 | 조정한 값을 처음 상태인 일반 대화로 되돌릴 때 |

버튼을 누른 뒤 **한 문장 말하기 → 잠깐 침묵하기**를 반복해 보세요. 입이 적당히 움직이면 그대로 사용하면 됩니다. 이 버튼들은 여러 반응 값을 함께 바꾸므로 기존에 따로 조절한 값도 바뀝니다.

## 3. 반응을 조금씩 조정하기

슬라이더는 가로 막대의 손잡이를 마우스로 끌어 값을 바꾸는 조작입니다. 한 번에 하나씩 바꾸고 같은 문장으로 비교하세요. 마음에 들지 않으면 **기본값**을 누르면 됩니다.

| 화면 이름 | 쉬운 뜻 | 조정 예시 |
|---|---|---|
| Noise Gate | 어느 정도 작은 소리를 무시할지 | 말하지 않아도 입이 열리면 -50에서 -45로 올려 보세요. |
| Sensitivity | 같은 소리에 얼마나 크게 반응할지 | 말할 때 반응이 약하면 1.00에서 1.20으로 올려 보세요. |
| Attack | 입이 열릴 때의 반응 시간 | 너무 늦게 열리면 40ms에서 20ms로 줄여 보세요. |
| Release | 입이 닫힐 때의 반응 시간 | 말이 끝나도 오래 열려 있으면 140ms에서 100ms로 줄여 보세요. |

이 수치는 시작 예시입니다. 마이크와 주변 소음에 따라 맞는 값이 달라집니다. `ms`는 시간 단위인 밀리초이며 1,000ms가 1초입니다. Attack과 Release는 값이 클수록 천천히 반응합니다.

### 말하지 않아도 입이 움직일 때

1. 주변이 조용한 상태에서 잠깐 말을 멈춥니다.
2. **Noise Gate**를 조금씩 올립니다. **-50보다 -45가 높은 값**입니다.
3. 평소 목소리로 말했을 때는 반응하는지 확인합니다.
4. 말에도 반응하지 않게 됐다면 조금 낮추거나 일반 대화를 다시 누릅니다.

Gate는 입력 크기만 봅니다. 키보드·선풍기·스피커 소리도 충분히 크면 반응할 수 있습니다.

### 말해도 입이 잘 안 열릴 때

1. **캐릭터 음소거**의 체크를 풉니다.
2. **조용한 목소리**를 누릅니다.
3. 필요하면 **Sensitivity**를 조금 올립니다. 0이면 입 반응이 사라집니다.
4. 계속 약하면 Windows에서 마이크 선택과 입력 볼륨을 확인합니다.

Gate가 입력을 막고 있으면 Sensitivity만 올려도 해결되지 않습니다. 다음 고급 입력 범위를 확인하거나 기본값으로 되돌린 뒤 다시 조정하세요.

### 조금만 말해도 입이 항상 크게 열릴 때

**Sensitivity**를 조금 낮춰 보세요. 반응 막대가 매번 끝까지 올라가는지와 작은 목소리·큰 목소리의 차이가 표현되는지 확인합니다.

## 4. 작은 목소리: 입력 반응 범위 — 필요할 때만

**반응** 탭 하단의 **낮은 입력 / 높은 입력**을 조절합니다.

- **낮은 입력**: 아주 작은 소리를 반응의 시작으로 보는 기준입니다.
- **높은 입력**: 큰 소리를 최대 반응으로 보는 기준입니다.

조용한 목소리 프리셋으로 충분하면 이 부분은 그대로 두세요. 더 조정할 때는 다음 순서로 진행합니다.

1. 일반 대화 상태에서 작은 목소리가 반응하지 않으면 **낮은 입력**을 -50에서 -60으로 낮춰 봅니다.
2. **Noise Gate**도 -60 정도로 함께 낮춥니다.
3. 말할 때 반응하는지와 침묵할 때 입이 닫히는지를 확인합니다.
4. 입이 너무 쉽게 최대 크기로 열리면 감도를 낮추거나 높은 입력을 조금 올립니다.

낮은 입력은 높은 입력보다 작은 값이어야 합니다. 앱은 두 값이 겹치려 하면 다른 쪽 값을 함께 조정합니다. 조정이 어려워졌다면 **기본값**으로 되돌리세요.

## 5. 내 캐릭터 설정 (선택 사항)

### 이미 준비된 캐릭터 파일을 받았다면

1. **PNG 시트 불러오기**를 클릭합니다.
2. 받은 파일을 찾아 선택하고 **열기**를 누릅니다.
3. 캐릭터 적용 완료 안내를 확인합니다.
4. 마이크가 중지된 상태에서 **마이크 없이 데모**를 눌러 입·눈 움직임을 확인한 뒤 Stop을 누릅니다.

실패하면 기존 캐릭터가 유지됩니다. **기본 캐릭터**를 누르면 패키지의 기본 캐릭터로 돌아갑니다. 개인 늘보군 패키지는 `Characters/늘보군.png`를 기본으로 사용하며 공개 앱은 내장 고양이를 사용합니다. 그림을 바꿔도 반응 조정값이 기본값으로 돌아가지는 않습니다.

### 그림을 직접 준비하거나 제작자에게 요청한다면

PNG 시트는 **입 세 가지 × 눈 두 가지 표정을 한 이미지에 배치한 파일**입니다. 일반 사진이나 캐릭터 그림 한 장만으로는 여섯 상태를 표현할 수 없습니다.

제작자에게 아래 문구를 전달하면 됩니다.

> VoxPet용 투명 PNG 시트를 만들어 주세요. 정사각형 칸을 가로 3개, 세로 2개 배치하고, 각 칸은 512×512px로 해주세요. 전체는 1536×1024px입니다. 첫 줄은 눈 뜸, 둘째 줄은 눈 감음이며, 왼쪽부터 입 닫힘·중간·열림입니다. 모든 칸에 같은 몸 크기의 완전한 캐릭터와 투명 여백이 필요합니다. 8비트 RGBA PNG, 16MB 이하로 주세요.

| 줄 / 칸 | 왼쪽 | 가운데 | 오른쪽 |
|---|---|---|---|
| 위쪽: 눈 뜸 | 입 닫힘 | 입 중간 | 입 열림 |
| 아래쪽: 눈 감음 | 입 닫힘 | 입 중간 | 입 열림 |

`px`는 이미지 크기의 단위이고, `RGBA`는 투명도를 포함하는 이미지 형식입니다. 제작자가 설정할 항목이며 앱에서 숫자를 입력할 필요는 없습니다. 칸 크기는 128~1024px까지 허용되며 위 512px는 제작 예시입니다.

앱이 각 표정의 중앙과 발밑 위치를 맞추지만 몸 크기는 바꾸지 않습니다. 각 칸이 비어 있거나 투명 여백이 없으면 거부됩니다. 본인이 이용할 권리가 있는 그림을 사용하세요.

**일반 PNG 시트 불러오기는 재실행 때 다시 선택해야 합니다.** 표정 슬롯의 **슬롯 PNG 선택 → 슬롯 저장**을 사용하면 복사본이 저장되어 다음 실행에도 유지됩니다.

## 6. OBS에 캐릭터 넣기 (방송하는 분만)

OBS는 방송·녹화 화면을 구성하는 별도 프로그램입니다. VoxPet만 사용하려면 이 부분은 건너뛰어도 됩니다. 아래는 OBS가 이미 설치되어 있는 경우의 순서입니다.

1. VoxPet에서 **초록 배경 (OBS)**을 체크합니다.
2. **캐릭터 방송창 열기 ↗**를 눌러 `VoxPet Character` 창을 엽니다.
3. OBS에서 사용할 **장면**을 선택합니다.
4. **소스** 영역의 **+**를 누르고 **윈도우 캡처 / Window Capture**를 선택합니다.
5. 이름은 `VoxPet 캐릭터`처럼 알아보기 쉽게 적고 확인을 누릅니다.
6. **창** 항목에서 **VoxPet Character**가 들어간 창을 선택합니다.
7. 캡처 방식에서 **Windows Graphics Capture** 또는 **Windows 10(1903 이상)**으로 표시되는 방식을 선택합니다. 표기는 OBS 버전에 따라 다릅니다.
8. 확인을 누르고 OBS 미리보기에 캐릭터가 보이는지 확인합니다.
9. 방금 만든 소스에서 마우스 오른쪽 클릭 → **필터**를 엽니다.
10. **효과 필터**의 **+**를 누르고 **크로마 키 / Chroma Key**를 추가합니다.
11. 키 색상 종류에서 **초록색 / Green**을 선택합니다.
12. 배경이 없어지고 캐릭터가 남으면 필터 창을 닫습니다. OBS 미리보기에서 크기와 위치를 맞춥니다.

크로마 키는 지정한 색의 배경을 지우는 기능입니다. 개인 캐릭터에 초록색이 들어 있으면 그 부분도 지워질 수 있으므로 결과를 확인하세요.

VoxPet의 **방송창 항상 위**를 체크하면 창이 다른 창 위에 표시됩니다. 방송창을 옮기려면 캐릭터나 배경을 누른 채 끌고, 크기를 바꾸려면 오른쪽 아래 모서리를 끕니다.

이 캡처 소스는 캐릭터 화면을 넣는 역할입니다. **목소리 송출은 OBS의 마이크 오디오 설정에서 별도로 확인**하세요. VoxPet의 Stop이나 캐릭터 음소거로 OBS 마이크가 꺼지는 것은 아닙니다.

검은 배경이나 빈 화면이 나오면 대상 창과 캡처 방식을 다시 확인하고 초록 배경/크로마 키 경로로 시험하세요. 초록 배경 체크를 풀면 VoxPet 창은 투명해지지만 사용자의 OBS 환경에서도 배경이 투명하게 잡히는지는 따로 확인해야 합니다. 창 캡처의 방식 설명은 [OBS 공식 안내](https://obsproject.com/kb/window-capture-sources)에 있습니다.

## 7. 설정이 저장되는 범위와 초기화

설정을 마친 뒤 **Stop → 메인 창의 ×** 순서로 정상 종료하세요. 저장 버튼은 따로 없습니다.

| 항목 | 다음 실행에도 남나요? |
|---|---|
| Noise Gate, Sensitivity, Attack, Release, 낮은/높은 입력 | 정상 종료 때 저장됩니다. |
| 방송창 항상 위, 초록 배경 | 정상 종료 때 저장됩니다. |
| 선택한 마이크 | 다시 확인하고 선택하세요. |
| 개인 캐릭터 PNG | 다시 불러와야 합니다. |
| 캐릭터 음소거와 데모 실행 상태 | 유지되지 않습니다. |

### 앱 안에서 되돌리기

- 반응값을 되돌리려면 **기본값**을 누릅니다.
- 그림을 되돌리려면 **기본 캐릭터**를 누릅니다.
- 방송창 옵션은 **방송창 항상 위**, **초록 배경 (OBS)**의 체크를 직접 바꿉니다.

### 저장된 설정 전체를 새로 시작하기 — 필요할 때만

1. VoxPet을 완전히 닫습니다.
2. Windows **파일 탐색기**를 엽니다. 작업 표시줄의 폴더 모양 아이콘으로 열 수 있습니다.
3. 위쪽 **주소 표시줄**을 클릭합니다. 검색 상자가 아니라 현재 폴더 위치가 표시되는 긴 칸입니다.
4. `%LOCALAPPDATA%\VoxPet`을 붙여 넣고 Enter를 누릅니다. 이 글자는 명령어가 아니라 설정 폴더의 주소입니다.
5. 폴더의 `settings.json` 파일을 찾습니다. 파일 끝부분이 숨겨져 있으면 `settings`로 보일 수 있습니다.
6. 파일을 오른쪽 클릭하고 **이름 바꾸기**를 선택해 `settings-backup.json`으로 바꿉니다. 이름이 `settings`로만 보이면 `settings-backup`으로 바꿉니다.
7. VoxPet을 다시 실행합니다. 기본 설정으로 시작합니다.

폴더나 파일이 없으면 아직 저장된 설정이 없는 것이므로 이름을 바꾸지 않고 그대로 시작하면 됩니다. 원래 파일을 보관했으므로 복구하려면 앱을 닫고 새로 생성된 settings 파일을 다른 이름으로 옮긴 다음 보관한 파일의 이름을 원래대로 돌리세요. 설정 파일의 내용을 직접 수정할 필요는 없습니다.

## 설정이 잘 안 맞을 때

**기본값 → 일반 목소리로 한 문장 말하기 → 침묵하기**부터 다시 시작하세요. 반응이 없으면 [사용 중 문제 해결](usage.md#사용-중-막혔을-때)을 확인하세요.

실제 마이크·사용자 GPU/OBS·물리 화면 배율의 남은 검증 상태는 [검증 기록](../quality/windows-checklist.md)을 따릅니다. 이 안내가 모든 컴퓨터 환경에서의 동작을 보장하는 것은 아닙니다.


## 표정·단축키와 눈물 설정

1. 상단 **표정** 탭을 눌러 **표정 · 단축키 슬롯**을 엽니다.
2. **편집할 슬롯**에서 F1~F12 중 하나를 고릅니다. 이름과 기본 표정을 선택합니다.
3. **눈물** 탭에서 **눈 깜빡임**, **눈물 모션**을 체크합니다. F3은 처음에 슬픈 표정과 눈물로 준비되어 있습니다.
4. 내 캐릭터의 표정 이미지를 사용하려면 **슬롯 PNG 선택**을 누릅니다. 위 캐릭터 설정과 같은 3열×2행 시트입니다. 내장 얼굴을 사용자 그림에 덧그리지 않으므로 표정은 그림에 직접 넣어야 합니다.
5. **눈물** 탭의 왼쪽/오른쪽/높이 슬라이더로 위치를 맞추고 **표정 미리보기**를 누릅니다. 작은 미리보기와 방송창에서 같은 모습으로 표시됩니다.
6. **슬롯 저장**을 누릅니다. 해당 슬롯의 단축키와 버튼이 저장한 표정을 사용합니다.

Ctrl+Shift+F1~F11은 다른 앱을 사용할 때도 동작합니다. Ctrl+Shift+F12는 Windows 예약 키 때문에 VoxPet 설정창/방송창을 클릭한 상태에서만 동작합니다. 충돌로 등록하지 못한 키는 화면에 표시합니다. 해당 키는 앱 안에서 누르거나 슬롯 버튼을 사용하세요.

저장은 즉시 `%LOCALAPPDATA%\VoxPet\Expressions`에 반영되며 시작할 때 F1 슬롯을 표시합니다. 원본 PNG를 이동해도 관리 복사본은 유지됩니다. **내장 표정 사용 → 슬롯 저장**으로 해당 슬롯을 패키지의 기본 캐릭터로 바꿀 수 있습니다. 전체 표정 초기화는 앱 종료 후 Expressions 폴더 이름을 바꿔 보관하세요. settings.json 초기화는 표정 슬롯에 영향을 주지 않습니다.

눈물과 깜빡임은 Stop/캐릭터 음소거 중에도 동작합니다. 자세한 규격과 복구는 [표정 슬롯 안내](../user-guide.md#표정-슬롯과-단축키)를 따릅니다.

## 주변 소음으로 Noise Gate 추천받기

1. 마이크를 고르고 **Start**를 누릅니다. 데모나 중지 상태에서는 측정할 수 없습니다.
2. **주변 소음 측정 (3초)**를 누르고 3초 동안 말하지 마세요. 방송에서 평소 들리는 팬/키보드 등 주변 소리만 측정합니다.
3. 추천값이 나오면 **추천값 적용**을 누르고 작은 목소리와 평소 목소리로 말해 입 반응을 확인합니다. 적용 전까지 기존 설정을 유지하며 Gate만 바꿉니다.
4. 작은 목소리가 잘리면 Gate를 조금 낮추세요. 말하면서 측정하면 추천값이 너무 높을 수 있으므로 조용히 다시 측정하세요.

**측정 취소**, Stop, 장치 중단, 프리셋/기본값, 앱 종료는 측정과 대기 추천을 취소합니다. 무신호·오래된 입력·너무 큰 소음에서는 추천하지 않고 기존 설정을 유지합니다. 이 기능은 주변 음량을 기준으로 값을 추천하며 말소리와 소음을 구별하거나 잡음을 제거하지 않습니다. 음성은 저장·전송하지 않습니다.

## 탭과 방송창 크기

상단 마이크·반응·캐릭터·표정·눈물 탭으로 설정을 선택합니다. 편집값은 탭 전환으로 초기화되지 않습니다. 캐릭터 탭에서 방송창을 열고 너비·높이를 각각 200~1200 DIP로 조정하세요. 오른쪽 아래 모서리 드래그와 우클릭 크기 메뉴도 사용할 수 있습니다. 크기는 이번 실행 동안 유지되며 재시작하면 480×480으로 시작합니다.

세부 탭 안내: 마이크 → 입력 / 음소거·권한, 반응 → 음량 / 소음 측정 / 속도 / 입력 범위, 캐릭터 → 미리보기 / 방송창 / PNG, 표정 → 전환 / 편집 / PNG / 테스트. 눈물 탭은 깜빡임·눈물 위치와 미리보기·저장을 표시합니다.


## 늘보군 표정과 상세 입 반응

개인 plan016 패키지는 평상·기쁨·슬픔·화남·놀람·졸림·부끄러움·뿌듯함·갸우뚱·신남·애정·장난의 서로 다른 늘보군 얼굴12종을 포함합니다. **표정 → 테스트**에서12개 버튼으로 개별 얼굴을 확인하거나 **12종 전체 테스트**로 순회합니다. 입력이 중지되어 있으면 마이크 없이 숫자 데모로 입 움직임도 표시하고, 완료/중지하면 원래 표정과 입력 상태로 돌아옵니다. 이미 실행 중인 마이크나 데모는 유지합니다. 개별 표정 또는 슬롯 전환은 전체 테스트를 끝내고 새 표정을 표시합니다. 테스트는 저장한 슬롯/PNG를 바꾸지 않습니다. 이전 저장값이 있으면 새 얼굴을 기본 슬롯에 자동 덮어쓰지 않으므로 테스트 탭에서 모두 확인하세요. 해당 슬롯을 새 늘보군 얼굴로 바꾸려면 표정→편집에서 종류를 선택하고 표정→PNG의 내장 표정 사용 후 슬롯 저장을 누릅니다.

입은 닫힘부터 최대 열림까지8단계로 반응합니다. RAW dBFS가 Gate·입력 범위·감도·Attack/Release를 거친0~1 반응값에 따라 바뀌므로 고정된 절대 데시벨 표가 아닙니다. 실제 목소리를 듣거나 감정을 판별하지 않습니다. 조용한 목소리가 잘리지 않게 Gate/입력 범위를 맞추고 감도를 조절하세요. 무음·Stop·입 음소거는 입을 닫으며 깜빡임과 눈물은 독립적으로 동작합니다.

기존3열×2행 PNG/저장 슬롯은 계속 지원합니다. 상세 PNG는 정사각형 셀8열×2행이며 위쪽은 눈 뜸, 아래쪽은 눈 감음, 왼쪽부터 입이 점차 커집니다. 상세 셀은128~512px, 기존3열은128~1024px, 파일은16MB 이하8비트 RGBA입니다. 기본 파일은 Characters/늘보군.png, 표정별 파일은 Characters/늘보군-표정/happy.png, sad.png, angry.png, surprised.png, sleepy.png, shy.png, smug.png, confused.png, excited.png, love.png, playful.png입니다. 표정 파일이 잘못되거나 없으면 평상 시트를 사용하며 기존 설정을 삭제하지 않습니다. 개인 자산은 공개 Git/CI에 포함하지 않습니다.


## 표정 순서 변경

**표정 → 편집**에서 슬롯을 고른 뒤 **↑ 위로 / ↓ 아래로**를 누릅니다. 순서는 즉시 저장되며 다음 실행에도 유지됩니다. 표시된 F1~F12 버튼과 단축키, 테스트 버튼은 새 순서를 따릅니다. 표정 이름·눈물·PNG와 저장하지 않은 편집 초안은 함께 유지됩니다. 처음/마지막 항목은 해당 방향 이동 버튼이 꺼집니다. 저장 실패 시 기존 순서를 유지합니다.

순서는 `%LOCALAPPDATA%\VoxPet\Expressions\order.json`에 별도로 저장합니다. 파일이 없거나 손상되면 원래 슬롯 순서를 사용하며 슬롯 JSON/PNG는 보존합니다. 기본 순서로 돌아가려면 앱을 종료하고 order.json만 다른 이름으로 옮겨 보관합니다. 방송창 우클릭 메뉴는 흰 배경과 검정 글씨로 표시합니다.


## OBS32.2.2에서 캐릭터가 보이지 않을 때

1. VoxPet의 **캐릭터 → 방송창 → OBS 호환 방송창 열기**를 누릅니다. 초록 배경의 독립 방송창이 열립니다.
2. OBS 소스에 **창 캡처**를 추가하고 대상 창을 **[VoxPet.exe]: VoxPet Character**로 선택합니다. 설정창 VoxPet · 목소리로 움직이는 캐릭터와 구분합니다.
3. 캡처 방식은 **Windows 10(1903 이상)**을 먼저 선택합니다. 이는 Windows11에서도 사용하는 방식입니다. 캡처 방식 자동 선택에서 빈 화면이 나오면 명시적으로 이 방식을 선택합니다.
4. 소스의 눈 아이콘을 켜고 우클릭→변환→화면에 맞추기로 잘못된 크롭/위치를 초기화합니다. 다른 불투명 소스가 위에서 가리지 않는지 확인합니다.
5. 필터→효과 필터→크로마 키에서 초록색을 제거합니다. 설정창은 트레이로 숨겨도 방송창은 계속 표시됩니다. 방송창 자체를 최소화하지 마세요.

새 초록 배경은 불투명 방송창으로 표시해 캡처 호환성을 높입니다. 초록 배경을 끄면 투명 방송창을 다시 만드므로 OBS 대상 창을 다시 확인하세요. 크기/위치와 캐릭터 모델은 유지합니다. 실제 GPU/Windows 캡처 결과는 다를 수 있으며 [OBS 창 캡처 설명](https://obsproject.com/kb/window-capture-sources)을 따릅니다.

## 실행 직후 종료 문제와 오류 기록

plan018은 표정 목록 초기화 중 선택값이 비어 이동 버튼에서 발생하던 종료 오류를 수정했습니다. 이전 설정/표정 슬롯을 삭제하지 않아도 됩니다. 새 ZIP을 새 폴더에 모두 풀고 실행하세요. 시작 설정의 복구 가능한 오류는 창/안내를 유지합니다. 계속 실행할 수 없는 오류는 메시지를 표시하고 종료합니다. `%LOCALAPPDATA%\VoxPet\last-error.json`에는 마지막 오류 종류·코드·앱 메서드·버전·시간만 보관하며 음성/장치 이름/개인 PNG 경로나 오류 메시지는 기록하지 않습니다.
