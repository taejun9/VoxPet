# plan-025-reference-design Review

## Summary

QA 이후 단일 에이전트 자체 리뷰. 파란 강조색 다크 스튜디오 UI, 늘보군/펠리 선택, 이미지 세트 v1 조합 엔진과 제작 가이드·로컬 패키지를 검토했다. 외부 에이전트의 독립 리뷰는 수행하지 않았다.

## QA

- macOS: 공식 NuGet locked restore/취약성 확인, Release 경고0·오류0, Core199/199, formatter/analyzer 수정 없음, verify_base/verify_app/diff 검사 통과.
- 코드1dc9750의 [Windows 전체 QA](https://github.com/taejun9/VoxPet/actions/runs/38372703545): build/Core199/publish, WPF1487고유검사·실패0, 실제 데스크톱240화면의 PNG CRC/커버리지, 일반/서명 EXE 재시작 통과.
- [OBS 합성 QA](https://github.com/taejun9/VoxPet/actions/runs/38372703485) 통과. 기존 방송창의 합성 캡처이며 실제 사용자 방송/게임 시험과 구분한다.
- 새 엔진: 합성 PNG 등록/손상 등록 유지/두 창 공유/frozen 이미지, 무기 썸네일 여백, 전역 키 down·반복 억제·원래 창에 전달·해제, 슬롯/무기/소매/Anchor, 빠른 액션 재시작, 세트 복원 및 초기화 전 종료의 등록 보존 검사.
- 개인 패키지에는 기존 늘보군12PNG와 펠리1PNG를 로컬에서만 복사한다. 원본 byte equality와 ZIP CRC를 별도 로컬 보고서에 기록한다. 개인 PNG를 Git/CI에 전송하지 않는다.

## Findings

- 수정 완료: 새 화면 fixture의 가상 작업 영역이 runner 화면보다 커 캡처 예외 발생. 실제 SystemParameters.WorkArea를 사용한다.
- 수정 완료: 기본 문자열 ComboBox 템플릿이 흰 글씨를 적용한32검사 실패. 신규4개 선택값/팝업 TextBlock에 검정색을 명시한다. QA 계약을 낮추지 않았다.
- 수정 완료: 등록 정보 초기화 전에 종료하면 기본 설정으로 저장할 수 있던 경계. 초기화 완료 전 등록/편집/저장을 막고 Windows 회귀를 추가했다.
- 수정 완료: 액션/의상 선택 시 입력 훅 재등록으로 repeat 억제가 풀리지 않게 동일 구성은 유지한다. 세트 revision 변경과 종료에는 이전 대기 입력을 폐기한다.
- 규격 확인: 기본6파츠를 고정하고 의상·얼굴장식은 별도 레이어에서 숨김/Anchor를 따른다. 같은 포즈의 소매·무기가 누락되면 등록을 거부한다. 출력 Canvas/각도는 원본 그대로이며 썸네일만 투명 여백을 줄인다.
- 개인정보/회귀 확인: 오디오 엔진 변경·음성 파일·네트워크·웹캠 추가 없음. 기존 PNG/표정/의상·손동작은 호환 경로로 보존하며 retired 캐릭터 연결 설정을 삭제하지 않는다.
- 검토 범위 내 미해결 P1/P2 결함 없음.

## Residual Risk

실제 Windows11/마이크/OBS/게임의 포커스·권한 차이·입력 차단, 실제 DPI/다중 모니터 및 장시간 성능은 기존 실기 체크리스트에 남는다. 새 분리 파츠의 실제 캐릭터 그림은 제작 규격에 맞춰 외부에서 준비해야 한다. 제공 제작 틀은 합성 도형이며 개인 새 파츠의 시각 검증을 대체하지 않는다. 기존 개인 캐릭터는 완성 PNG 시트 경로로 계속 사용한다.

## Follow-Ups

실제 늘보군/펠리 분리 파츠·소매·무기 포즈 세트를 준비하면 로컬 등록 후 팔 중복/Anchor/음량과 게임 입력을 확인한다. 검증된 현재 결과만 main에 통합하고 Git 수명 절차를 완료한다.
