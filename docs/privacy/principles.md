# 마이크와 음성 데이터 원칙

MVP의 음성 데이터는 선택한 마이크의 실시간 레벨 분석에만 사용한다.
캡처 구현은 아래 계약을 따른다. verify_app.py로 금지 API 잔여를 검사하고 실제 점유 해제는 Windows 실기로 확인한다.

- 사용자가 Start를 누른 뒤 캡처하고 Running 상태와 선택 장치를 표시한다.
- Windows의 마이크 설정과 권한 거부를 존중한다. 숨은 자동 녹음/권한 우회를 추가하지 않는다.
- PCM은 계산에 필요한 짧은 메모리 버퍼로만 취급하며 파일 저장·네트워크 전송·원격 AI에 전달하지 않는다.
- Stop/종료/장치 변경 시 캡처·이벤트·타이머 자원을 해제하고 최신 음성 상태를 초기화한다.
- 레벨 숫자를 표시하지만 기본 영구 로그에는 PCM, 음성 내용, 장치 식별자를 남기지 않는다. 마지막 마이크 유지 요청에 따라 선택 endpoint ID만 로컬 settings.json에 저장하며 장치 이름/음성/측정값/오류 로그에는 포함하지 않는다.
- 디버깅 로그는 최소 오류 코드와 일반 상태만 사용한다. 실제 목소리·방송·계정·개인 경로는 샘플에 넣지 않는다.
- 테스트는 합성 PCM/dB와 가짜 장치를 사용한다. 실기 녹음 파일을 저장소에 넣지 않는다.
- 외부 PNG는 이용 권리와 라이선스를 확인한다. 라이선스 미확인 자산은 기본 캐릭터로 배포하지 않는다.

향후 STT/감정/원격 분석을 추가할 때는 목적·전송 대상·보관·사용자 통제를 별도 계획에 명시한다.
카메라, 추적, 광고, 결제, 파괴적 자동화는 이 기반의 범위에 포함되지 않는다.

주변 소음 추천은 사용자가 Start한 세션의 dBFS 숫자와 timestamp만 최대512개 임시 수집한다. PCM·음성 내용·측정 로그를 파일에 저장하지 않으며 추천 적용 후 Gate만 기존 설정으로 저장한다. 측정/취소/Stop/종료 뒤 표본 참조를 버린다. 권한 설정 바로가기는 사용자 클릭으로 OS 설정만 열며 권한을 자동 변경하지 않는다. Ctrl+Shift+M은 입 반응만 전환하므로 마이크 점유 해제는 Stop을 사용한다.

plan018 오류 진단은 로컬 last-error.json 한 파일에 마지막 오류의 시간·앱 버전·단계·예외 종류·HResult와 VoxPet 메서드 이름만 최대4예외/12메서드로 기록합니다. 예외 메시지/파일 경로/장치 식별자/PNG 내용/PCM은 기록하지 않으며 원격 전송하지 않습니다. 트레이 이동은 입력을 유지하고 Stop/종료로 해제합니다.

plan022는 마지막 선택 마이크를 복원해도 입력을 자동 Start하지 않습니다. 분리된 장치의 ID는 로컬 선호 값으로 유지하고 다시 연결해 새로고침하면 복원합니다. 사용자가 다른 장치를 선택하거나 표시된 장치로 Start하면 그 선택을 기억합니다. 일반 시작의 설정 읽기와 자동/종료 저장은 worker에서 수행하며 사용자 설정을 CI에 전송하지 않습니다.

손동작 좌클릭 기능은 사용자가 선택한 동작이 활성화된 동안에만 전역 좌버튼 down 신호를 받는다. 마우스 좌표·다른 버튼·창 내용·입력 기록은 읽거나 저장하지 않으며 원래 클릭을 전달한다. 사용 해제 또는 항상/간격/전역 키 모드로 변경하면 좌클릭 hook을 제거한다. 종료 시작에도 hook과 등록 키를 해제한다. 손동작·캐릭터 연결 설정은 로컬 motion.json에만 저장한다.


plan023 데스크톱 화면 증거는 일회용 GitHub Windows runner에 표시된 시험 앱 HWND 영역만 저장한다. 일반 사용자 실행에는 캡처하지 않으며 별도 webcam/화면 추적 기능을 제공하지 않는다. 공개 고양이와 합성 의상/시트·임시 설정만 사용한다. 사용자의 개인 PNG 외부 전송 금지 선택에 따라16개 PNG는 로컬 패키지에만 복사하고 원본 바이트를 보존한다. 음성/실제 endpoint/사용자 설정은 CI에 보내지 않는다.

plan025 이미지 세트는 상대 PNG 경로를 검증하고 로컬 보관함에 복사한다. 원본 경로·이미지를 원격으로 보내지 않는다. 전역 키 감지는 사용자가 직접 지정한 가상 키와 수정 키 상태만 비교한다. 지정되지 않은 키는 보관하지 않고 문자 변환/키 내용/마우스 좌표/게임 창 정보/입력 로그를 만들지 않는다. 입력은 원래 앱으로 전달한다. 좌클릭 감지는 기본 꺼짐이며 선택적으로 켠다. 등록 세트가 활성화되어 있고 입력 설정 중이 아닐 때만 훅을 사용한다. 종료·기존 PNG 전환 때 훅과 대기 입력을 해제한다. Windows QA의 키 입력과 세트 이미지는 공개 합성 자료만 사용한다.
