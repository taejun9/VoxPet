# 마이크와 음성 데이터 원칙

MVP의 음성 데이터는 선택한 마이크의 실시간 레벨 분석에만 사용한다.
현재 저장소에는 캡처 코드가 없으며 아래는 구현 시 지켜야 할 계약이다.

- 사용자가 Start를 누른 뒤 캡처하고 Running 상태와 선택 장치를 표시한다.
- Windows의 마이크 설정과 권한 거부를 존중한다. 숨은 자동 녹음/권한 우회를 추가하지 않는다.
- PCM은 계산에 필요한 짧은 메모리 버퍼로만 취급하며 파일 저장·네트워크 전송·원격 AI에 전달하지 않는다.
- Stop/종료/장치 변경 시 캡처·이벤트·타이머 자원을 해제하고 최신 음성 상태를 초기화한다.
- 레벨 숫자를 표시하지만 기본 영구 로그에는 PCM, 음성 내용, 장치 식별자를 남기지 않는다.
- 디버깅 로그는 최소 오류 코드와 일반 상태만 사용한다. 실제 목소리·방송·계정·개인 경로는 샘플에 넣지 않는다.
- 테스트는 합성 PCM/dB와 가짜 장치를 사용한다. 실기 녹음 파일을 저장소에 넣지 않는다.
- 외부 PNG는 이용 권리와 라이선스를 확인한다. 라이선스 미확인 자산은 기본 캐릭터로 배포하지 않는다.

향후 STT/감정/원격 분석을 추가할 때는 목적·전송 대상·보관·사용자 통제를 별도 계획에 명시한다.
카메라, 추적, 광고, 결제, 파괴적 자동화는 이 기반의 범위에 포함되지 않는다.
